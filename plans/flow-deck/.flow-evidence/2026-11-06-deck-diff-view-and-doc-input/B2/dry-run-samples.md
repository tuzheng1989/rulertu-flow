# B2 纸面推演：改后理想回复结构样例

对 evals 1 与 eval 7 的 prompt 各推演一段改后理想收尾回复，验证与修订后手册（mode-deepdive.md 输出格式 / mode-creative.md 第 5 步四件套）自洽。

## 样例 1 · eval 1（research-direction-deep-dive）

prompt：「我在研究大模型在医疗诊断中的应用，帮我深挖一下这个方向还能怎么深入。」

理想回复结构（洞察段 → 过程摘要一行 → 边界段）：

```markdown
（开场宣告 + 深度四问照常先行展示，开钻——这些是开工交互，不在收尾回复中重复铺陈）

## 🔬 研究方向深挖 - 深度下钻

### 💎 核心洞察
1. **本质问题**：瓶颈不在模型能力而在"可问责性"——误诊责任无人承担使临床落地卡在最后一公里
   （验证：对比近两年 FDA 对 AI 辅助诊断的获批/拒批案例，看拒批理由是否集中于责任归属）
2. **差异点**：与主流"辅助阅片"的差异在于从"给建议"转向"给可核查的鉴别诊断链"
   （验证：arXiv 检索 structured differential diagnosis，确认无同行工作把鉴别链作主交付物）
3. **增量判定标准**：在公开数据集上证明能指出放射科医生漏诊案例并给出可追溯影像学依据
   （验证：取 2 个公开腹部 CT 数据集试跑，误报率对照科室基线）
4. 最原始材料：FDA De Novo 数据库、院内 PACS 脱敏样本、放射科质控会议记录（而非综述论文）

*过程摘要：钻探计划——专家之差=临床决策链的岗责设计／原始材料=监管库与院内影像／方法工具=回顾性对照试验／外部裁判=FDA 获批先例；下钻——"模型能力不足"假设被证伪，转向责任机制。说"看过程"即完整展开。*

### 🔗 边界之外
多科室横向比较属广度铺开（说"切换扩散"）；选哪个切入点收敛决策建议 /grilling。
```

自洽性检查：洞察置顶且为主体（4 条）；每条附一行验证方式（外部验证方式必填未削弱）；钻探计划与下钻过程各一行摘要、不铺陈；被证伪假设出现在摘要行（深度的证据保留）；边界一句。与 mode-deepdive.md 修订后输出格式节逐项对应。

## 样例 2 · eval 7（mode-dispatch-with-reference-design）

prompt：「参考盲盒机制，帮我设计我们产品的功能发布节奏，想要意料之外但靠谱的方案。」

理想回复结构（宣告 → 设计卡 ×n 四件套）：

```markdown
本轮判定为创意模式，判据：有参考物（盲盒）+ 要设计某物（发布节奏）+ 要"意料之外"。
（第 1-4 步内部照常执行：盘点需求与约束、解构盲盒为 2 条生效机制附生效条件清单、
四透镜关联写关联路径、双轴筛选+查新——过程记录在此从略，主回复只给过筛的设计卡。）

## 💡 盲盒式功能发布
- **成立依据**：需求[发布节奏缺乏期待感] ← 参考[盲盒：不确定性奖励]；生效条件核对——低风险单次决策（不更新无损失）满足、结果保密到发布瞬间（补偿：预告只给主题词）、系列可感知（按季命名）满足
- **设计描述**：季度功能打包成不定期"惊喜版本"：上线前只公布主题，发布当天揭晓全部内容
- **意外点**：软件发布惯例是 changelog 预告 + 灰度公告，本设计偏离在刻意保留不确定性
- **试金石**：两个发布周期对 10% 用户隐藏预告，对比更新及时率与社区自发讨论量

## 💡 收集进度条式发布
- **成立依据**：需求[发布信息零散难追踪] ← 参考[盲盒：收集完整性执念]；生效条件核对——系列可感知（按主题命名）满足、收集有回报（彩蛋页）满足
- **设计描述**：全年发布按主题成系列，集齐命名系列解锁团队公开彩蛋页
- **意外点**：发布惯例按版本号组织信息，本设计偏离在按"可收集的系列"组织
- **试金石**：发布 3 期后统计追更率（连续查看两期以上发布说明的用户占比）是否高于改版前

（3-5 个，按意外程度从近到远排序，并明示排序不代表可行性/成本/收益预测。）
```

自洽性检查：五步流程内部执行不断言进回复（盘点/解构/筛选不铺陈）；主回复以设计卡为主体；每卡四件套，「成立依据」一行合并关联路径+生效条件核对结论；试金石必填在卡内；双轴筛选结果体现为「意外点锚定惯例」；排序声明保留。与 mode-creative.md 修订后第 5 步逐项对应。

## 推演结论

两样例均可在修订后手册条款下完整生成，无条款互斥；evals 1/7 改写后的 expected_output 与样例结构一致。
