# 为代理编写文档

本参考适用于任何由代理消费的文档，例如技能、`AGENTS.md`、`CLAUDE.md`，以及通过指针按需读取的说明。封装形式可以不同，写作原则相同：目标是让代理每次采用一致的**过程**，而不是强求每次产生相同输出。

编写公开技能时，再读取 [skill-mechanics.md](skill-mechanics.md)；普通内部参考不需要技能 frontmatter。

## 上下文指针

**上下文指针**是代理当前上下文中指向外部材料的短说明，同时编码何时应读取该材料。技能的 `description` 是一种指针，`AGENTS.md` 中指向另一份文档的行也是指针。

决定代理是否可靠读取材料的是指针的措辞，而不是目标文件本身。重要材料藏在弱指针后面会产生执行波动：先强化触发措辞，只有强化后仍不可靠时才考虑内联。

指针承担两个职责：说明材料是什么，以及列出哪些**分支**会触发它。分支是文档处理的一类独立情况。指针常驻上下文，因此应比正文更严格地裁剪：

- **前置引导词**：把最能触发正确行为的词放在前面；
- **每个分支一个触发条件**：同义词不算多个分支，应合并重复表达；
- **删除正文已经承载的身份说明**：指针只保留发现和路由所需内容。

## 两种负载

每增加一份文档或指针，都会消耗以下预算之一：

- **上下文负载**：每轮都进入代理窗口的内容，例如技能描述、`AGENTS.md` 行；无论是否触发都消耗 token 和注意力。
- **认知负载**：由人记住存在哪些文档、何时调用。它不是必须消灭的成本，而是人类保留判断权的代价；只在确实需要人判断时承担。

通过指针按需读取的材料只承担指针本身的上下文负载；完全没有指针的材料则全部依赖人的认知负载。

## 信息层级

代理文档由两类内容构成：

- **步骤**：代理按顺序执行的动作；
- **参考**：按需查询的定义、规则和事实。

内容按“代理多快需要它”放在三个层级：

1. **文件内步骤**：主流程，按顺序执行；
2. **文件内参考**：运行中普遍需要、按需查询的规则；
3. **外置参考**：只有特定分支需要，通过上下文指针加载。

下沉太少会让主文件膨胀；下沉太多会隐藏代理真正需要的信息。判断标准是分支：所有分支都需要的内容留在主文件，只有部分分支需要的内容放入外置参考。

**渐进披露**：把分支性参考下沉到指针后，使主流程保持清晰。它首先是保护信息层级的方法，其次才是 token 优化。

**共置**：同一概念的定义、规则和例外放在同一标题下。不要把一个概念的碎片散落在全文各处。

**蔓延**：文件即使每行都有用，也可能因过长而稀释注意力。解决办法是按分支或执行序列拆分，让每条路径只携带自身需要的材料。

## 步骤与完成条件

每个步骤都要以**完成条件**收口，即代理能够判断该步骤已经完成的状态。完成条件有两个关键属性：

- **清晰度**：代理能否区分完成与未完成。“已经理解”过于模糊，会诱发提前结束。优先把边界改成可检查状态；只有边界无法进一步明确且确实观察到抢跑时，才通过真正的上下文边界拆分后续步骤。
- **要求强度**：“列出改动”与“逐一覆盖所有改动模型”要求不同。强条件会驱动必要的查证工作。完成条件既应可检查，也应穷尽任务范围。

## 何时拆分

拆分会增加上下文负载或认知负载，只有收益明确时才做：

- **按序列拆分**：后续步骤会诱使代理匆忙结束当前步骤时，把后续步骤移出当前上下文；
- **按调用方式拆分**：仅适用于公开技能，规则见 [skill-mechanics.md](skill-mechanics.md)。

## 引导词

**引导词**是模型预训练中已经存在、能够稳定唤起一组行为的紧凑概念，例如“曳光弹”“战争迷雾”。重复使用同一个词，比多处重复整段定义更省 token，也更容易让代理形成一致行为。

引导词同时服务两个位置：

- 在正文中锚定执行行为；
- 在指针中锚定触发条件。

优先使用模型已经熟悉的概念。自造词需要额外定义，除非它能显著提升一致性，否则不划算。

**否定式引导**容易激活被禁止的行为。优先正向说明目标行为，例如写“注释保持单行”，而不是只写“不要写长注释”。只有无法改写的硬护栏才保留禁止语句，并同时说明应该采取的正向动作。

## 裁剪

- **单一事实来源**：同一含义只保留一个权威位置。重复会增加维护成本，也会人为放大该规则的重要性。
- **环境也是事实来源**：`package.json`、配置、目录和 `--help` 已能直接说明的内容，不要在文档中复制。文档只缓存难以从环境发现的约定、原因和陷阱。
- **逐行检查相关性**：删除与当前任务无关、已经过时或应当下沉到分支参考的内容。缺乏裁剪会形成沉积层。
- **删除无效指令**：如果一句话不会改变模型相对于默认行为的表现，它就是空操作。直接删除整句；若引导词太弱，则换成更有辨识度的词，而不是堆叠同义修饰。
