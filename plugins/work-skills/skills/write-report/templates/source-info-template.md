## 转换说明

### 章节划分
- 章节按照原文档的 H2 标题层级划分
- 每个章节保存为独立的 chapter-*.md 文件
- 章节序号采用两位数字格式 (01, 02, 03...)

### 格式保留

| 内容类型 | 保留方式 |
|---------|---------|
| 代码块 | 完整保留，保持语言标识 |
| 表格 | 转换为 Markdown 表格格式 |
| 图片 | 保留为 Markdown 图片引用格式 |
| 超链接 | 保留并添加来源注释 |

### 引用处理

- **原文引用**: 所有超链接已保留
- **来源标注**: 外部链接添加 `[来源: URL]` 注释
- **参考资料**: 外部链接索引保存在 `references/index.md`
