# Research Node: Source Summarizer

## 任务描述

将新的搜索结果整合到现有研究摘要中，采用增量式总结策略避免重复内容。

## 输入参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `research_topic` | string | 研究主题 |
| `research_brief` | string | 研究简报（**摘要分段维度从此读取**） |
| `running_summary` | string | 当前累积摘要（可能为空） |
| `search_results` | array | 新搜索结果（每条含 title / url / snippet / **source_type**） |
| `loop_count` | number | 当前循环次数 |
| `is_first_loop` | boolean | 是否为首轮循环 |
| `compress_threshold_chars` | number | 摘要压缩阈值（默认 3000，超长时主控触发 compress） |

## 输出格式

> **v0.4.0 变更**：摘要的分段**遵循 research_brief 的「必须覆盖的维度」清单**（每个维度一个小节），不再使用固定的「核心概念/主要特点/...」分段。下方模板中的分段仅为示例，实际以 brief 维度为准。

```markdown
## 研究摘要：{research_topic}

### 核心概念
{主题的核心定义、基本概念和关键术语}

### 主要特点
{主题的主要特征和属性}

### 应用场景
{实际应用领域和案例}

### 技术原理
{技术层面的工作机制和原理（如适用）}

### 发展现状
{当前的发展状态和趋势}

### 挑战与局限
{面临的主要挑战和局限性}

### 相关资源
{重要的资源、工具或参考}
```

## 执行逻辑

### 首轮循环 (is_first_loop == true)

创建初始摘要，建立研究框架。

**策略：**
1. 分析所有搜索结果，提取核心信息
2. 建立清晰的分段结构
3. 为重要观点标注来源 [n]
4. 保持客观中立的语气

### 后续循环 (is_first_loop == false)

增量更新现有摘要。

**策略：**
1. **保留结构**: 保持现有摘要的核心框架
2. **有机融合**: 将新信息融入相关段落
3. **避免重复**: 识别并去除重复内容
4. **填补缺口**: 优先补充未覆盖的维度
5. **更新引用**: 为新增内容使用新的引用编号

## 摘要结构规范

### 必选分段

- **核心概念**: 定义、术语、基本概念
- **主要特点**: 特征、属性、关键点

### 可选分段（根据主题类型）

| 主题类型 | 建议分段 |
|---------|---------|
| 技术类 | 技术原理、实现方式、工具框架 |
| 学术类 | 理论基础、研究方法、学术观点 |
| 商业类 | 市场现状、竞争格局、商业模式 |
| 产品类 | 产品功能、使用场景、用户评价 |

### 通用分段

- **应用场景**: 实际应用、案例研究
- **发展现状**: 当前状态、最新进展
- **挑战与局限**: 面临的挑战、局限性

## 引用格式规范

### 在文本中引用

```markdown
根据研究 [1]，量子计算对传统密码学构成重大威胁。
专家指出 [2]，需要开发抗量子密码算法。
```

### 引用编号规则

- 首轮：从 [1] 开始编号
- 后续：继续递增编号，不重复使用

### 交叉验证与来源层次标注【v0.5.0 新增】

利用 `search_results` 的 `source_type` 字段做轻量标注（**不破坏 running_summary 结构，不强制字段化**）：

- **交叉验证标记**：被 ≥2 个独立来源支持的关键事实，句末标 `✓交叉验证`；仅单源的高风险事实（关键数字/时间/结论）标 `⚠单源待核`。
  - 例：`NIST 已于 2024 年发布 ML-KEM 标准 [1][2] ✓交叉验证`
  - 例：`某产品吞吐量达 10K QPS [3] ⚠单源待核`
- **来源层次**：原始/官方来源（`source_tier: primary` 或官方/监管来源）的事实，可在 `[n]` 旁轻量标注来源类型，如 `[n, 官方]` / `[n, 学术]`，便于读者判断可信度。
- **取舍**：只对关键事实标注，普通叙述性内容不标，避免噪声。

## 研究摘要：量子计算在密码学中的应用

### 核心概念
量子计算是一种基于量子力学原理的计算模式，利用量子比特的叠加和纠缠特性实现并行计算。在密码学领域，量子计算对传统密码系统构成重大威胁 [1]。

### 主要特点
- 能够在多项式时间内破解 RSA、ECC 等公钥密码系统 [1]
- 需要开发抗量子密码算法以应对未来威胁 [2]

### 技术原理
传统公钥密码基于大整数分解、离散对数等数学难题，而量子计算机使用 Shor 算法可以高效解决这些问题 [1]。

### 发展现状
NIST 正在开展抗量子密码算法的标准化工作，包括基于格、基于哈希、基于编码等多种方案 [2]。

### 挑战与局限
- 抗量子算法通常需要更大的密钥尺寸和更长的计算时间
- 标准化进程仍在进行中，尚未完全成熟 [2]
```

## 注意事项

1. **信息质量**: 确保摘要基于搜索结果，避免添加外部知识
2. **结构一致性**: 保持摘要结构的一致性，便于后续更新
3. **引用准确**: 确保每个引用都能对应到具体的搜索结果
4. **长度控制（去重 ≠ 压细节）**: 单轮摘要建议不超过 2000 字；若融入后 `running_summary` 超过 `compress_threshold_chars`（默认 3000），主控流程将触发 compress 节点。**融入时去除重复表述与冗余过渡，但务必保留具体事例、量化数据、对比案例——这些是最终报告展开的素材；不得为控长而丢弃有信息量的细节。** 摘要可以"短"，但必须"信息密度高"，而不是"颗粒粗"。
