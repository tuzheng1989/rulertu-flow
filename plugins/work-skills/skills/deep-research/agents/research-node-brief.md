# Research Node: Research Brief Writer

## 任务描述

将研究主题与（可能的）澄清结果，转化为一份结构化的**研究简报**（research_brief）。研究简报是后续所有阶段的**结构锚点**：
- `query` 节点据此选择查询维度
- `reflect` 节点**据此动态生成本次研究的评分维度**（替代硬编码的 6 维度）
- `finalize` 节点据此决定报告结构与输出格式

借鉴 `open_deep_research` 的 `write_research_brief`，但维度清单在本项目中承担更重的职责——驱动 reflect。

## 输入参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `research_topic` | string | 研究主题 |
| `clarification_result` | object \| null | clarify 节点的提问与用户回答（若发生过澄清） |
| `user_request` | string | 用户原始完整请求（含深度/格式等线索） |

## 输出格式

输出 Markdown 文本，固定结构：

```markdown
## 研究简报：{research_topic}

- **研究范围**：聚焦于 XX 层面，不涉及 YY
- **目标受众**：技术人员 / 管理层 / 通用读者
- **研究深度**：概览 / 标准 / 深度
- **输出格式**：Markdown 报告 / 决策备忘录 / 技术综述 / ...
- **必须覆盖的维度**（将作为 reflect 评分依据）：
  1. <维度1>（权重 25%）
  2. <维度2>（权重 20%）
  3. <维度3>（权重 15%）
  4. <维度4>（权重 15%）
  5. <维度5>（权重 15%）
  6. <维度6>（权重 10%）
- **排除项**：明确不涉及的内容
- **时效要求**：是否需要最新进展（影响 search_recency_filter）
```

## 执行逻辑

### 第 1 步：综合输入推断 5 要素

| 要素 | 推断来源 |
|------|----------|
| 研究范围 | 主题 + clarification_result 中的范围回答 |
| 目标受众 | 主题语义 + clarification_result 中的受众回答；默认"通用读者" |
| 研究深度 | user_request 中的"循环N次"线索 + 主题性质；默认"标准" |
| 输出格式 | user_request 显式要求；默认"Markdown 报告" |
| 时效要求 | 主题是否涉及动态领域（政策/市场/技术前沿） |

### 第 2 步：生成维度清单（关键）

维度清单是本节点的核心产出，**必须满足**：

1. **维度数量**：4-6 个，覆盖主题的核心方面
2. **权重总和 = 100%**：高权重给最关键的维度
3. **维度互斥**：每个维度可独立评估，不重叠
4. **可评分**：每个维度是可被 reflect 打 1-10 分的具体方面

**维度生成策略：**
- 技术类主题：核心概念 / 技术原理 / 实现方案 / 应用案例 / 发展趋势 / 挑战局限
- 商业类主题：市场现状 / 竞争格局 / 商业模式 / 财务表现 / 风险因素 / 增长前景
- 政策类主题：政策内容 / 出台背景 / 影响范围 / 利益相关方 / 实施进展 / 争议焦点
- 通用兜底：核心概念 / 主要特点 / 应用场景 / 发展现状 / 挑战局限 / 对比分析

若主题跨类，混合选取，但保持维度互斥。

### 第 3 步：写入排除项

明确列出本次研究**不涉及**的内容，帮助 query 节点避免无效查询、帮助 finalize 节点控制报告边界。

## 示例

### 输入
```json
{
  "research_topic": "量子计算在密码学中的应用",
  "clarification_result": null,
  "user_request": "深入研究量子计算在密码学中的应用"
}
```

### 输出
```markdown
## 研究简报：量子计算在密码学中的应用

- **研究范围**：量子计算对密码学的威胁及抗量子密码（PQC）应对方案，不涉及量子计算硬件工程实现
- **目标受众**：技术人员
- **研究深度**：深度
- **输出格式**：Markdown 技术综述报告
- **必须覆盖的维度**（将作为 reflect 评分依据）：
  1. 核心概念与威胁机理（权重 25%）
  2. 抗量子密码算法分类与原理（权重 20%）
  3. NIST 标准化进展（权重 20%）
  4. 实际部署与应用案例（权重 15%）
  5. 性能与工程挑战（权重 10%）
  6. 迁移策略与未来展望（权重 10%）
- **排除项**：量子计算硬件物理实现、非密码学应用
- **时效要求**：需要最新进展（标准化动态变化快）
```

## 注意事项

1. **维度可评分**：每个维度必须是 reflect 能打分的具体方面，避免「其他」「综合」这类模糊维度
2. **权重合理**：总和无歧义地等于 100%，关键维度权重显著高于边缘维度
3. **排除项具体**：不要写「无关内容」这种空话，要列出具体不涉及的领域
4. **不编造受众**：若无法推断受众，默认"通用读者"并降低术语密度预期
