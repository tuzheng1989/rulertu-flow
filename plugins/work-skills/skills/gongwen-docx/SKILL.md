# 公文 DOCX 转换

将 Markdown + YAML frontmatter 格式的文档转换为符合 GB/T 9704-2012 标准的党政机关公文 DOCX。

## 用法

```
python {baseDir}/scripts/gongwen-to-docx.py <input.md> -o <output.docx>
```

### Agent 执行步骤

1. 确定 SKILL.md 所在目录为 `{baseDir}`
2. 读取输入 MD 文件，验证 frontmatter 完整性（`title` 为必填字段）
3. 确定输出路径：用户或项目指令有指定时用指定值；否则默认输出到输入文件同目录、同名 `.docx`
4. 执行转换脚本
5. 向用户报告结果

## 输入格式

输入文件为 Markdown。

**有 frontmatter 的公文格式：**

```markdown
---
title: 关于XXX的通知          # 必填：公文标题
doc_type: 通知                 # 可选：通知 | 报告 | 请示 | 批复 | 函（不填则通用格式）
doc_number: XX〔2026〕X号      # 可选：发文字号
issuer: XXX单位                # 可选：发文机关署名
recipient: 各相关单位           # 可选：主送机关
date: 2026-06-09               # 可选：成文日期
cc: 单位A，单位B               # 可选：抄送机关
attachments:                   # 可选：附件列表
  - 附件1：XXX明细表
reference_doc: 引用的来文       # 可选：仅批复类型使用
---

一、背景说明

正文段落内容...

(一) 具体要求

详细说明...
```

**无 frontmatter 的普通文档：**

如果文件没有 YAML frontmatter（没有 `---` 包围的元数据块），脚本会自动使用文件名作为标题，并按**普通文档模式**处理：仅应用公文的字体样式，跳过红线、发文字号、主送机关等公文特有元素。

```markdown
# 文档标题

正文内容，支持**粗体**和*斜体*格式...

## 二级标题

更多内容...
```

### Markdown 格式支持

支持的标准 Markdown 格式：
- `**粗体**` → 粗体
- `*斜体*` → 斜体
- `## 标题` → 节标题（黑体三号），无需配合中文编号即可渲染为标题样式
- 中文编号自动识别：`一、` `(一)` → 一/二级公文标题
- 无序列表 `-` / `*` / `+` → 列表项，按行首缩进体现层级，前缀 `•` 圆点
- 有序列表 `1.` `2.` → 连续编号智能识别为有序列表（保留编号、按层级缩进）；孤立的 `1.` 仍按公文三级标题处理
- 行内 `**粗体**`、`*斜体*` 在列表项与节标题中同样生效

### 公文字类型差异

| 类型 | 主送机关 | 引用语 | 默认结语 |
|------|---------|--------|---------|
| 通知 | ✅ | — | — |
| 报告 | ✅ | — | 特此报告。 |
| 请示 | ✅ | — | 妥否，请批示。 |
| 批复 | ✅ | ✅ (reference_doc) | 此复。 |
| 函 | ❌ | — | — |
| 不指定 | ✅ | — | — |

### 正文标题编号规则

正文中使用中文编号会被自动识别为公文层级标题：

| 级别 | 编号格式 | 字体 | 示例 |
|------|---------|------|------|
| 一级 | 中文数字 + 顿号 | 黑体 | `一、工作背景` |
| 二级 | 中文数字 + 括号 | 楷体 | `(一) 总体要求` |
| 三级 | 阿拉伯数字 + 点 | 仿宋加粗 | `1. 具体措施` |

也支持 Markdown `#` 前缀（如 `# 一、背景` 会被正确识别为一级标题）。

行内 `**粗体**` 和 `*斜体*` 会被保留。

## 格式规范要点

输出 DOCX 严格遵循 GB/T 9704-2012：

- **页面**：A4 纵向，天头 37mm / 地脚 35mm / 订口 28mm / 翻口 26mm
- **标题**：居中，二号（22pt），方正小标宋简体（未安装时回退为宋体+加粗）
- **正文**：仿宋三号（16pt），固定 28pt 行距，首行缩进 2 字符
- **红线**：发文字号下方红色分隔线
- **落款**：右对齐，发文机关署名 + 成文日期
- **页码**：页脚居中，宋体四号（14pt）

完整格式规范参见 `references/gbt9704-reference.md`。

## 常见问题

| 错误 | 原因 | 解决 |
|------|------|------|
| 文件不存在 | 输入路径错误 | 检查文件路径是否正确 |
| 方正小标宋简体未安装 | 系统缺少标准字体 | 自动回退为宋体+加粗（非致命警告） |
| **粗体** 未生效 | Markdown 格式问题 | 确保使用 `**text**` 格式（两边各两个星号） |
| 标题层级未识别 | 中文编号格式不对 | 使用 `一、` `(一)` `1.` 格式，或 `#` 前缀 |

**关于 frontmatter：**

- 有 frontmatter：按完整公文格式处理（红线、发文字号、主送机关等）
- 无 frontmatter：按普通文档处理（仅应用字体样式，标题用文件名）
