# 战略思维框架详解

本文档定义了 6 大战略思维框架的标准元数据，供 AI 在分析过程中调用。

这些框架不是"分析模型"——它们不产出具体的分析结论，而是指导"怎么想"：如何拆解问题、如何检验假设、如何避免思维陷阱。

## 第一性原理推导

### 核心定义

打破行业惯例和类比思维，从最基本的事实和物理/经济/人性规律出发，重新推导战略结论。避免"别人怎么做我们就怎么做"的从众思维。

### 适用场景

- 技术路线选型（回归业务本质需求）
- 商业模式设计（为什么这个生意能赚钱？）
- 颠覆式创新决策（行业惯例是否已经过时？）
- 产品定位（用户最根本的需求是什么？）

### 使用方法

1. **识别惯例假设**：列出行业内"大家都这么做"的惯例，追问"为什么？"
2. **拆解到基本事实**：将问题拆解到无法再拆解的基本事实
   - 经济事实：成本结构、价值链、规模效应
   - 人性事实：用户行为动机、决策心理
   - 技术事实：技术边界、物理限制
3. **从基本事实重新推导**：不受惯例约束，从基本事实出发推导最优方案
4. **与惯例对比**：重新推导的方案和行业惯例有什么不同？差异的根源在哪里？

### 避坑提示

- 不要把"常识"等同于"基本事实"——常识可能是行业惯性
- 不要为了不同而不同——如果惯例确实是最优解，承认它
- 基本事实必须是可验证的，不能是新的未验证假设

## 战略假设识别与检验

### 核心定义

任何战略判断都建立在一系列隐含假设之上。本框架的核心是将这些假设显性化，逐一评估其可靠性和可验证性，确保战略不是建立在沙堆上。

### 适用场景

- 任何涉及重大投入的战略决策
- 商业模式验证
- 新市场进入前的可行性评估
- 创业项目评估

### 使用方法

1. **提取战略假设**：从战略判断中反推——"如果这个判断是对的，那它建立在什么前提上？"
2. **假设分类**：
   - **核心假设**：如果不成立，结论完全推翻
   - **支撑假设**：影响结论的强度，但不致命
   - **边界假设**：限定结论的适用范围
3. **检验评估**：
   - **已有证据**：是否有数据或事实支撑？
   - **可验证性**：能否设计验证方法？
   - **证伪可能**：什么情况下这个假设会被推翻？
4. **风险分级**：
   - 🟢 已验证的假设（有充分数据支撑）
   - 🟡 有支撑但不充分的假设（需要持续关注）
   - 🔴 关键但未验证的假设（需要优先验证或降低依赖）

### 避坑提示

- 不要只列假设不检验——列出来只是第一步
- 特别关注那些"大家都这么认为"的假设，它们最危险
- 核心假设如果无法验证，考虑降低对其的依赖（寻找替代方案）

## 反面论证（Red Team / 杀戮测试）

### 核心定义

主动组建"反对派"来攻击自己的战略结论。不是找毛病，而是以"如果结论是错的"为前提，系统性地寻找推翻它的理由。目标是提前发现自己的盲区。

### 适用场景

- 对任何核心战略建议的最终检验
- 竞争策略制定（模拟对手视角）
- 投资决策（寻找杀死投资的理由）
- 产品战略（如果产品失败了，最可能因为什么？）

### 使用方法

1. **陈述结论**：清晰写出你的战略判断和建议
2. **角色代入**：假设你是对手/竞争者/持不同意见者
3. **系统性攻击**（至少从以下角度）：
   - **事实攻击**：支撑结论的数据是否有误？来源是否可靠？
   - **逻辑攻击**：推理链条中有没有跳跃或循环论证？
   - **替代解释**：同样的现象是否可以用完全不同的逻辑解释？
   - **极端情景**：在什么极端条件下结论完全失效？
   - **利益盲区**：建议者是否因为自身利益而忽略某些信息？
4. **评估攻击强度**：每个攻击的可信度如何？
5. **修正结论**：根据攻击结果调整结论或增加前提条件

### 避坑提示

- 不要走过场——攻击必须真诚，不是为了"走形式后证明自己是对的"
- 如果找不到有效的攻击角度，要么结论确实很强，要么攻击不够努力
- 攻击结果必须体现在最终结论中，不能"攻击完了还是原来的结论"

## 二阶效应分析

### 核心定义

每个决策都有直接结果（一阶效应）和间接后果（二阶及更高阶效应）。本框架强迫思考"然后呢？"——战略决策的连锁反应和长期影响。

### 适用场景

- 技术架构决策（技术选型的长期影响）
- 产品策略调整（功能增减的连锁反应）
- 竞争策略（价格战、补贴等决策的长期后果）
- 组织变革（结构调整的间接影响）

### 使用方法

1. **列出一阶效应**：决策的直接、预期结果
2. **追问"然后呢？"**：每个一阶效应发生后，会引发什么？
3. **绘制效应链**：
   ```
   决策 → 一阶效应 → 二阶效应 → 三阶效应
        → 一阶效应 → 二阶效应
        → 一阶效应 → 二阶效应 → ...
   ```
4. **识别关键二阶效应**：
   - 哪些二阶效应会改变一阶效应的价值判断？
   - 哪些二阶效应是延迟出现的（短期内看不到，长期才显现）？
   - 哪些二阶效应是不可逆的？
5. **综合评估**：在考虑二阶效应后，决策的总收益/总风险如何变化？

### 避坑提示

- 不要无限推导——通常到二阶就够了，三阶以上不确定性太大
- 特别关注延迟效应和不可逆效应——这两类最容易让人后悔
- 不要因为存在负面二阶效应就否决好的决策——关键看净效应

## 情景规划

### 核心定义

承认未来不可精确预测，设计多个可能的未来情景，在每个情景下评估战略表现。目标不是预测未来，而是找到在各种可能情况下都表现良好的稳健战略。

### 适用场景

- 不确定性高的战略决策
- 长期战略规划（3 年以上）
- 受外部因素（政策/技术/市场）影响大的决策
- 投资决策（不同市场情景下的回报）

### 使用方法

1. **识别关键不确定性**：哪些因素对结果影响最大但最不可预测？
2. **构建情景**（通常 3 个）：
   - **基准情景**：最可能发生的未来（中性预期）
   - **乐观情景**：关键因素朝有利方向发展
   - **悲观情景**：关键因素朝不利方向发展
3. **情景不宜太极端**——每个情景都应该是"可能发生的"，而非"理论上可能的"
4. **在每个情景下评估战略**：
   - 这个战略在这个情景下表现如何？
   - 有没有在所有情景下都表现良好的战略？
5. **制定稳健策略**：
   - 核心策略：在大多数情景下都有效的行动
   - 情景特异策略：仅在特定情景下触发的行动
   - 预警信号：什么信号出现时需要切换策略？

### 避坑提示

- 不要把情景规划变成概率计算——重点不是哪个情景更可能，而是策略是否稳健
- 情景之间应该有质的差异，不只是程度不同
- 每个情景都要足够具体，能指导实际行动

## 权衡分析（Trade-off）

### 核心定义

战略的本质是取舍——选择 A 就意味着放弃 B。本框架将每个选项的代价显性化，确保决策者清楚"选择意味着放弃什么"。

### 适用场景

- 多方案对比决策
- 资源分配优先级
- 增长模式选择（广度 vs 深度）
- 技术/产品/市场方向选择

### 使用方法

1. **列出选项**：明确所有可选方案
2. **对每个选项做"得到/放弃"分析**：
   - **得到什么**：选择这个选项带来的核心价值
   - **放弃什么**：选择这个选项意味着不能做什么
   - **不可逆程度**：选错了能回头吗？回头的代价多大？
3. **跨选项对比**：
   - 哪些选项的"放弃"是可以接受的？
   - 哪些选项的"不可逆程度"超出了风险承受能力？
   - 是否存在"既要又要"的幻想？如果有，打破它
4. **做出取舍**：
   - 明确选择及理由
   - 明确放弃及放弃的理由
   - 设定回顾条件：什么情况下需要重新评估这个取舍？

### 避坑提示

- 不要回避取舍——"我们全都要"不是战略
- 特别关注隐性成本——有些"放弃"不是显而易见的
- 短期代价和长期代价可能不同——要分开评估
- 不要因为某个选项"什么都能做"就选它——通常意味着什么都不精
