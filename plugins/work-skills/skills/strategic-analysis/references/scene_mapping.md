# 战略分析场景映射指南

本文档定义了 6 大场景族及其对应的思维框架、分析模型组合和匹配逻辑。

---

## 场景族 1：业务战略

### 1a. 战略方向选择（进入/退出/转型）

**典型用户输入**：
- "我们公司要不要从 ToC 转 ToB？"
- "现在要不要进入 XX 赛道？"
- "要不要砍掉这条业务线？"
- "公司面临转型，有两个方向，帮我分析选哪个"

**推荐工具组合**：
1. **思维框架**：权衡分析（显性化每个选项的代价）→ 假设检验（验证各选项的隐含假设）
2. **分析模型**：SWOT（各选项的优劣势对比）→ 安索夫矩阵（增长路径匹配）→ 波特五力（目标方向的竞争强度）
3. **专项框架**：商业模式画布（如涉及商业模式重构）

**必填信息**：
1. 当前业务状况和核心痛点
2. 考虑的方向/选项（至少两个）
3. 核心资源和能力
4. 关键约束（资金/时间/团队）
5. 决策时间压力

**首选输出格式**：战略选项对比矩阵 + 战略决策备忘录

---

### 1b. 战略规划与定位

**典型用户输入**：
- "帮我制定未来 3 年的战略规划"
- "公司要做战略转型，帮我分析一下"
- "重新定位一下我们的品牌"
- "帮我梳理一下公司的战略方向"

**推荐工具组合**：
1. **思维框架**：情景规划（多情景下的战略表现）→ 二阶效应（战略的长期连锁反应）
2. **分析模型**：PEST（宏观趋势）→ 波特五力（行业竞争）→ SWOT（综合定位）→ 麦肯锡 7S（组织能力匹配，可选）
3. **专项框架**：精益画布/商业模式画布（如涉及商业模式梳理）

**必填信息**：
1. 公司当前业务描述
2. 核心产品/服务
3. 目标市场
4. 主要竞争对手
5. 公司核心资源与能力

**首选输出格式**：完整战略分析报告 + 战略路线图

---

### 1c. 商业模式设计与验证

**典型用户输入**：
- "帮我设计一下这个项目的商业模式"
- "这个商业模式能不能跑通？"
- "帮我验证一下这个商业想法"

**推荐工具组合**：
1. **思维框架**：第一性原理（从基本事实推导商业逻辑）→ 假设检验（商业模式的核心假设是什么？能否验证？）
2. **分析模型**：SWOT → 盈亏平衡分析（最低生存门槛）→ 风险矩阵
3. **专项框架**：商业模式画布/精益画布（核心工具）→ PMF 框架（产品市场匹配验证）

**必填信息**：
1. 产品/服务描述
2. 目标客户群体
3. 收入模式设想
4. 核心成本结构
5. 竞争优势来源

**首选输出格式**：完整战略分析报告 + 风险与不确定性评估

---

## 场景族 2：市场与竞争战略

### 2a. 新市场进入

**典型用户输入**：
- "我要做一个国产美妆品牌进入东南亚市场的分析"
- "我的产品想进入美国市场，评估一下可行性"
- "想进入新赛道，做个市场进入分析"
- "我们想开拓下沉市场"

**推荐工具组合**：
1. **思维框架**：假设检验（市场进入的核心假设）→ 情景规划（乐观/保守/悲观情景）
2. **分析模型**：PEST（宏观环境）→ TAM/SAM/SOM（市场规模）→ 波特五力（竞争格局）→ STP（市场定位）
3. **专项框架**：PMF 框架（验证产品在新市场的匹配度）

**必填信息**：
1. 当前产品/品牌
2. 目标市场/地区
3. 核心竞争优势
4. 目标客群特征
5. 进入方式考虑（代理/直营/合作）

**首选输出格式**：完整战略分析报告 + 战略路线图

---

### 2b. 竞争策略制定

**典型用户输入**：
- "帮我分析一下和竞品的差距"
- "制定竞争策略"
- "对标一下主要竞争对手"
- "怎么应对 XX 的竞争？"

**推荐工具组合**：
1. **思维框架**：Red Team / 杀戮测试（如果我方策略被破解，最可能因为什么）→ 权衡分析（进攻 vs 防御的取舍）
2. **分析模型**：竞品对标分析 → SWOT 对标 → 波特五力（行业层面）→ 蓝海战略画布（可选，寻找差异化空间）
3. **专项框架**：PMF 框架（各方产品市场匹配对比）

**必填信息**：
1. 自身产品/品牌
2. 主要竞争对手
3. 对比维度（功能/价格/渠道等）
4. 目标客群
5. 当前市场地位

**首选输出格式**：战略选项对比矩阵 + 战略决策备忘录

---

### 2c. 行业与市场格局分析

**典型用户输入**：
- "帮我分析一下新能源汽车行业"
- "这个行业的市场格局是怎样的"
- "做个行业分析"
- "XX 行业还有没有机会？"

**推荐工具组合**：
1. **思维框架**：第一性原理（行业本质是什么）→ 二阶效应（技术/政策变化的连锁反应）
2. **分析模型**：PEST（宏观环境）→ 波特五力（竞争格局）→ 行业生命周期模型（发展阶段）→ 波特价值链（价值分布）
3. **专项框架**：产品生命周期（如涉及具体产品品类）

**必填信息**：
1. 目标行业
2. 分析目的（投资/创业/求职/战略规划）
3. 关注的细分领域
4. 分析周期（短期/中期/长期）
5. 地域范围

**首选输出格式**：完整战略分析报告

---

## 场景族 3：产品战略

### 3a. 产品路线图与优先级

**典型用户输入**：
- "帮我规划一下产品路线图"
- "接下来产品应该做什么？"
- "多个需求怎么排优先级？"
- "产品未来一年的规划怎么做？"

**推荐工具组合**：
1. **思维框架**：权衡分析（做什么 vs 不做什么的取舍）→ 二阶效应（各选择的长期影响）
2. **分析模型**：STP（目标市场）→ SWOT（产品优劣势）
3. **专项框架**：Kano 模型（需求分类和优先级）→ 产品生命周期（当前阶段策略）

**必填信息**：
1. 产品当前状态和阶段
2. 核心用户群体
3. 已知的需求/功能候选列表
4. 团队资源和能力
5. 时间约束

**首选输出格式**：战略路线图 + 战略决策备忘录

---

### 3b. 产品定位与差异化

**典型用户输入**：
- "产品应该怎么定位？"
- "怎么和竞品差异化？"
- "我们的产品核心卖点应该是什么？"

**推荐工具组合**：
1. **思维框架**：第一性原理（用户最根本的需求是什么）→ Red Team（差异化能否被轻易模仿）
2. **分析模型**：STP（精准定位）→ 竞品对标分析（差异化空间）
3. **专项框架**：Kano 模型（哪些差异点是兴奋型需求）→ PMF 框架（定位是否匹配目标市场）

**必填信息**：
1. 产品描述
2. 目标用户
3. 主要竞品
4. 产品核心功能/特色
5. 目标市场特征

**首选输出格式**：战略选项对比矩阵 + 完整战略分析报告

---

### 3c. 产品组合策略

**典型用户输入**：
- "产品线太多了，怎么精简？"
- "应该做多产品还是聚焦一个？"
- "产品组合怎么优化？"

**推荐工具组合**：
1. **思维框架**：权衡分析（广度 vs 深度的取舍）→ 二阶效应（产品间的相互影响）
2. **分析模型**：SWOT → 波士顿矩阵（明星/金牛/问题/瘦狗）→ 安索夫矩阵（增长方向）
3. **专项框架**：产品生命周期（各产品所处阶段）→ Kano 模型（资源分配优先级）

**必填信息**：
1. 现有产品线/产品列表
2. 各产品营收贡献
3. 各产品增长趋势
4. 资源约束
5. 战略目标

**首选输出格式**：战略选项对比矩阵 + 战略路线图

---

## 场景族 4：技术战略

### 4a. 技术路线选型

**典型用户输入**：
- "技术选型，选 A 还是 B？"
- "我们应该用什么技术栈？"
- "要不要迁移到 XX 技术？"
- "自研还是用开源方案？"

**推荐工具组合**：
1. **思维框架**：第一性原理（业务真正需要什么技术能力）→ 假设检验（技术承诺 vs 现实）→ 权衡分析（各方案的取舍）
2. **分析模型**：SWOT（各技术方案的优劣）
3. **专项框架**：Gartner 技术成熟度曲线（技术所处阶段判断）→ Build vs Buy vs Partner（自研/采购/合作决策）

**必填信息**：
1. 业务场景和需求
2. 候选技术方案
3. 团队技术能力
4. 时间和资源约束
5. 长期技术愿景

**首选输出格式**：战略选项对比矩阵 + 风险与不确定性评估

---

### 4b. 技术投资优先级

**典型用户输入**：
- "技术建设应该优先投什么？"
- "技术债和新功能怎么平衡？"
- "技术团队的方向怎么定？"

**推荐工具组合**：
1. **思维框架**：权衡分析（短期 vs 长期、技术债 vs 新功能）→ 二阶效应（技术投资不足的长期后果）
2. **分析模型**：SWOT → 风险矩阵（不做的风险）
3. **专项框架**：技术债务评估框架（量化技术债影响）→ Gartner 技术成熟度曲线（判断投入时机）

**必填信息**：
1. 当前技术现状和痛点
2. 待投资的技术项目列表
3. 各项目的业务价值
4. 资源和预算约束
5. 业务优先级

**首选输出格式**：战略路线图 + 战略决策备忘录

---

### 4c. 技术架构演进规划

**典型用户输入**：
- "技术架构怎么演进？"
- "系统架构的未来规划怎么做？"
- "微服务化/云原生化是否合适？"

**推荐工具组合**：
1. **思维框架**：第一性原理（架构演进的业务驱动力）→ 二阶效应（架构决策的长期影响）→ 情景规划（不同增长速度下的架构表现）
2. **分析模型**：SWOT → 风险矩阵
3. **专项框架**：技术债务评估（当前架构的技术债）→ Gartner 技术成熟度曲线（目标技术的成熟度）

**必填信息**：
1. 当前架构描述
2. 业务增长预期
3. 当前架构痛点
4. 团队技术能力
5. 演进时间框架

**首选输出格式**：战略路线图 + 风险与不确定性评估

## 场景族 5：增长与运营战略

**典型用户输入**：
- "帮我提升用户增长"
- "制定增长策略"
- "怎么获取更多用户？"

**推荐工具组合**：
1. **思维框架**：第一性原理（增长的根本驱动力）→ 假设检验（增长假设的验证）
2. **分析模型**：AARRR（增长漏斗）→ STP（目标用户精准定位）
3. **专项框架**：PMF 框架（增长前先确认产品市场匹配）

**必填信息**：
1. 产品类型
2. 当前用户规模
3. 主要获客渠道
4. 当前增长瓶颈
5. 增长目标

**首选输出格式**：战略路线图 + 完整战略分析报告

---

### 5b. 用户运营与留存

**典型用户输入**：
- "用户留存率太低，怎么改善？"
- "怎么做用户分层运营？"
- "怎么提高用户活跃度？"

**推荐工具组合**：
1. **思维框架**：假设检验（用户流失的真正原因）→ 二阶效应（留存改善措施的间接影响）
2. **分析模型**：AARRR（聚焦 Retention 环节）→ RFM（用户分层）
3. **专项框架**：Kano 模型（哪些功能驱动留存）→ 产品生命周期（产品阶段的留存策略）

**必填信息**：
1. 产品类型
2. 当前留存数据
3. 用户流失原因（已知）
4. 核心功能使用情况
5. 运营资源

**首选输出格式**：完整战略分析报告 + 战略路线图

---

### 5c. 商业化与变现

**典型用户输入**：
- "怎么实现商业化？"
- "变现模式怎么选？"
- "付费转化率怎么提高？"

**推荐工具组合**：
1. **思维框架**：第一性原理（用户为什么愿意付费）→ 权衡分析（变现 vs 用户体验的平衡）

3. **专项框架**：商业模式画布（变现逻辑梳理）→ Kano 模型（哪些功能值得付费）

**必填信息**：
1. 产品类型和用户规模
2. 当前变现模式（如有）
3. 用户付费意愿
4. 竞品变现模式
5. 变现目标

**首选输出格式**：战略选项对比矩阵 + 完整战略分析报告

## 场景识别规则

| 关键词 | 可能场景族 |
|--------|-----------|
| 战略选择、要不要做XX、选A还是B、进入/退出、转型 | 场景族 1a：战略方向选择 |
| 战略规划、战略转型、重新定位、战略目标 | 场景族 1b：战略规划与定位 |
| 商业模式、商业计划、商业想法、盈利模式 | 场景族 1c：商业模式设计与验证 |
| 新市场、进入市场、出海、下沉市场 | 场景族 2a：新市场进入 |
| 竞品、竞争对手、对标、差距分析、竞争策略 | 场景族 2b：竞争策略制定 |
| 行业分析、市场格局、行业趋势、行业机会 | 场景族 2c：行业与市场格局 |
| 产品路线图、产品规划、产品优先级、需求排期 | 场景族 3a：产品路线图与优先级 |

### 语义理解规则

当用户输入同时匹配多个场景时，按以下优先级判断：
1. 涉及"技术选型"或"技术方案" → 优先场景族 4
2. 涉及"产品路线图"或"产品规划" → 优先场景族 3
3. 涉及"进入市场"或"出海" → 优先场景族 2a
4. 涉及"创业"或"新项目" → 优先场景族 6c
5. 涉及"竞品"或"竞争" → 优先场景族 2b
6. 涉及"投资回报"或"财务" → 优先场景族 6a
7. 其他情况，综合关键词和上下文判断

### 边界外场景处理

对于超出 6 大场景族的分析需求：
1. 明确告知用户该场景不在核心覆盖范围
2. 提供可用的工具组合建议
3. 询问用户是否基于现有框架进行适配分析
