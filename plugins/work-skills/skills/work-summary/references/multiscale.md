# 分尺度融合

1. 确定总窗口、时区、主体、目标、结构、来源与上下文预算。列出不重叠的子窗口：月度可用日或周，季度用月，半年和年度用月或季度；跨边界的周切开。记录每个窗口的来源和缺口，按批读取，避免一次载入全部采集数据。
2. 发现工作区中的下级总结，读取元数据及正文，核对实际起止、时区、个人或团队归属、来源和主题。旧总结没有元数据时，从正文及可回查资料判断；无法确认时标为待核实线索。选择与总窗口相容的不重叠子窗口；重叠部分按原始记录或可定位的具体事件切分去重，不能精确切分时不重复计数，并注明缺口。窗口外事件不计入本期。
3. 分开建立两张覆盖清单：时间覆盖（每个子窗口和来源）及信息覆盖（用户要求的每个目标、主题、来源及重要例外）。月份齐全不等于主题齐全；总结未提及不等于事情未发生。对缺失的窗口、主题及重要例外补采原始资料；无法补采时在最终总结明确说明其对结论的限制。
4. 对每条候选记录时间、主体、项目或目标、状态、指标、证据位置和限制。时间、来源与结论边界清楚的下级内容可作为复用依据；时间或来源不清的内容只作回查线索。关键结论尽可能回查原始会话、文档或提交；无法回查时注明来自哪份下级总结及未独立核实，不将候选当作已验证事实。保留失败、异常、反例和验证边界；试点链路跑通不代表决策质量或长期可靠性已验证。
5. 按项目和目标融合相邻窗口及跨来源记录，保留关键状态变化、里程碑和遗留问题；分别描述技术交付、业务验证等对象的状态，阶段性完成不扩大为项目整体完成。去除同一事件的重复描述。
6. 每项指标保留时间范围、对象、单位和口径，区分新增量、累计量与时点存量。仅当范围不重叠、口径一致且数值可相加时汇总；累计量与存量一般分别呈现，不能逐期相加。无法证明可加时分别列出或省略合计。
7. 中间记录包含覆盖、证据定位、状态变化、指标、失败、冲突和缺口；逐层分批融合并保留索引。最终逐项检查目标、时间、证据和例外，明确限制。中间文件放用户指定位置或工作区临时目录，避免不必要地持久化和分享个人会话。
