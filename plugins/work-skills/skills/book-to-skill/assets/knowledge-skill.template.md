# {{书名}}知识工具

## 知识边界

本 Skill 是基于《{{书名}}》生成的结构化知识压缩结果，不是逐字原文。需要精确引用、参数、条款或争议核查时，回到原始书籍或对应 Source Skill。

## 使用流程

1. 从问题提取主题、概念、比较对象、因果关系和章节线索。
2. 先读 `references/index.md`，再读取最相关的章节、术语表或速查表。
3. 区分作者主张、作者证据和本 Skill 的结构化解释。
4. 检查反例、局限和相邻章节，不把摘要当成无条件结论。
5. 来源不足或存在争议时明确说明，不用常识补写成书中结论。

## 资源

- `references/overview.md`：全书骨架和主要局限。
- `references/chapters/`：章节知识压缩。
- `references/glossary.md`：作者术语。
- `references/patterns.md`：比较、因果和权衡模式。
- `references/cheatsheet.md`：快速查询表。

## 输出要求

- 先回答问题，再说明必要前提和局限。
- 需要精确来源时给出对应来源章节；不要伪造页码。
- 找不到依据时明确说“本书内容不足以回答”。
