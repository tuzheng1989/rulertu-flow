# Faithful 模式

## 目标

把原书变成可检索的外部知识源，保留章节语义、条件、例外和上下文，不做章节摘要，不自动纠错，不用模型常识补写。

适用于规则书、标准、操作手册、API 文档、教材、参考书、原始文献，以及任何需要精确依据的任务。

## 产物

```text
<book-slug>/
├── SKILL.md
└── references/
    ├── index.md
    ├── 00_前置内容.md          # 有前置内容时
    ├── 01_<chapter>/
    └── .book2skill-generated.json
```

`references/` 只保存来源内容及导航链接。不要混入摘要、评论、方法卡或模型推断。

## 执行

1. 提取并检查文本质量；空文本、明显乱码或错序时停止。
2. 优先按原书编号和自然语义边界切分。
3. 对稳定编号结构运行：

   ```bash
   python scripts/pipeline.py <book-path> --skill-dir <target-skill>
   ```

4. 无稳定编号时，由 Agent 语义切分，但仍遵守父子关系、数字排序和相对链接规则。
5. 先生成 references，再依据真实目录编写目标 `SKILL.md`。
6. 运行 `python scripts/validate_references.py <target>/references`。
7. 用至少 5 个代表性查询验证能定位到最具体章节；用至少 3 个任务验证条件、例外和冲突处理。

## 目标 SKILL.md

只写：

- 知识边界和具体触发场景。
- 输入检查。
- 从 `references/index.md` 到具体子章节的渐进检索顺序。
- 例外、限制、覆盖规则和冲突判断顺序。
- 信息缺失时如何停止、说明和追问。
- 交付前检查。

不要在主文件重复整书内容，也不要默认在回答中暴露内部文件路径。

## 冲突顺序

1. 明确例外、限制和覆盖条款优先。
2. 条件匹配的具体条目优先于通用条目。
3. 更深层子章节优先于父级概述。
4. 可选规则和附录只在启用条件成立时参与。
5. 来源内容无法消解时明确冲突，不擅自选择。

## 禁止

- 为了流畅而改写规则或阈值。
- 把疑似错误静默纠正成常识答案。
- 把模型生成的知识摘要放入 `references/`。
- 在未标记为 Book2Skill 生成的目录上使用 `--force`。
