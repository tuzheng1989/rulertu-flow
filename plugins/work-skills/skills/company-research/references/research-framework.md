# 公司调研报告框架

完整的公司调研报告方法论，包括标准版 9 章节模板、四类调研场景的结构权重表、以及每个场景的典型逻辑。

## 标准版调研报告模板（9 章节）

### 0. 研究结论（Executive Summary）

**建议先写结论**，这是报告最重要的部分，通常读者会首先查看。

**内容包括**：

#### 公司一句话定位
```
XX是一家专注于XX领域的XX公司，核心产品为XX。
```

示例：
- 字节跳动是一家全球领先的科技公司，专注于短视频和人工智能内容分发。
- OpenAI 是一家人工智能研究公司，专注于开发安全且有益的通用人工智能。

#### 核心竞争力（3-5 点）
列出公司的主要优势：

1. **技术领先** - 例如：拥有专利技术、算法优势
2. **客户资源稳定** - 例如：头部客户、高留存率
3. **行业增长快速** - 例如：所在赛道处于高速增长期
4. **品牌影响力强** - 例如：行业知名度、用户口碑
5. **团队能力突出** - 例如：创始人背景、核心团队经验

#### 主要风险（2-3 点）
列出公司面临的主要挑战：

1. **行业竞争加剧** - 例如：市场竞争激烈、新进入者增多
2. **商业模式尚未完全验证** - 例如：盈利模式不清晰、依赖单一收入来源
3. **技术风险** - 例如：技术迭代快、面临技术淘汰风险
4. **政策风险** - 例如：监管政策变化、合规要求提高
5. **人才流失风险** - 例如：核心人才不稳定、招聘困难

#### 未来发展判断
对公司未来发展方向的判断：

- **增长潜力** - 例如：市场空间大、增长驱动因素明确
- **战略方向** - 例如：产品规划、市场扩张计划
- **关键里程碑** - 例如：近期重要目标、长期愿景

#### 总体评价
一句话总结公司的整体情况：

```
公司在XX赛道具备一定优势，但仍处于成长阶段。
```

或：

```
公司综合实力较强，但面临XX挑战，建议关注XX风险。
```

### 1. 公司概况（Company Overview）

#### 1.1 基本信息

**必需条目**：
- **成立时间**: YYYY年MM月
- **注册地**: 城市/国家
- **创始人**: 姓名（如有）
- **员工规模**: 人数（如：150,000+）
- **融资情况/上市情况**: 轮次和金额 / 股票代码

**示例**：
```
成立时间：2012年3月
注册地：中国北京
创始人：张一鸣
员工规模：150,000+
融资情况：未上市（估值：$220B，2023年）
```

#### 1.2 发展历程

**关键里程碑表格**：

| 时间 | 事件 |
|------|------|
| XXXX年X月 | 公司成立 |
| XXXX年X月 | 发布核心产品 |
| XXXX年X月 | 完成A轮融资 |
| XXXX年X月 | 用户突破X千万 |
| XXXX年X月 | 进入XX市场 |

**示例**：
```
2012年3月 - 公司成立
2012年9月 - 发布今日头条
2016年9月 - 抖音上线
2017年11月 - 收购 Musical.ly
2020年3月 - TikTok 全球用户突破 20 亿
```

#### 1.3 管理团队

**核心成员表格**：

| 姓名 | 职位 | 背景 |
|------|------|------|
| 创始人 | CEO | 前XX公司YY职位，XX年经验 |
| 联合创始人 | CTO | 毕业于XX大学，前XX公司 |

**重点分析**：
- **创始团队能力** - 例如：技术背景、商业经验
- **行业经验** - 例如：在相关行业的工作年限
- **资源背景** - 例如：人脉资源、投资方支持

---

### 2. 产品与业务结构（Products & Business）

#### 2.1 核心产品

**描述**：
- **产品类型** - 例如：SaaS、移动应用、硬件、平台
- **产品功能** - 核心功能列表
- **使用场景** - 目标用户和典型场景

**示例**：
```
产品类型：短视频移动应用
产品功能：视频拍摄、编辑、分享、推荐算法
使用场景：用户UGC内容消费、创作者内容发布
```

#### 2.2 业务结构

**收入来源表格**：

| 业务 | 占比 | 增长 |
|------|------|------|
| 业务A | 40% | 快速增长（YoY +50%） |
| 业务B | 60% | 稳定（YoY +10%） |

**示例**：
```
广告收入：80%（快速增长）
电商佣金：15%（稳定增长）
其他增值服务：5%（初期阶段）
```

#### 2.3 技术能力（如适用）

**包括**：
- **技术路线** - 例如：AI 算法、云原生架构
- **专利** - 专利数量和类型
- **技术壁垒** - 例如：算法优势、数据积累

---

### 3. 客户与市场（Market & Customer）

#### 3.1 目标客户

**客户类型**：
- **B端 / C端** - 企业客户还是个人用户
- **行业分布** - 主要服务的行业
- **客户规模** - 大型企业 / SME / 个人

**示例**：
```
客户类型：C端用户
行业分布：全球市场（重点：美国、印度、巴西）
客户规模：18-35岁年轻人为主
```

#### 3.2 典型客户

**客户案例表格**：

| 客户 | 行业 | 使用产品 |
|------|------|---------|
| XX公司 | 制造业 | XX系统 |
| YY公司 | 零售 | XX平台 |

#### 3.3 市场规模

**三级市场分析**：
- **TAM（Total Addressable Market）** - 总市场
- **SAM（Serviceable Addressable Market）** - 可服务市场
- **SOM（Serviceable Obtainable Market）** - 可获得市场

**示例**：
```
TAM: 全球短视频市场 $100B
SAM: 移动短视频市场 $50B
SOM: 当前目标市场 $10B（预计3年内增长至 $20B）
```

---

### 4. 行业分析（Industry Analysis）

#### 4.1 行业结构

**行业链条**：
```
上游 → 核心技术（芯片、算法、云服务）
中游 → 产品服务（应用、平台、内容）
下游 → 终端客户（用户、企业）
```

#### 4.2 行业规模

**包括**：
- **市场规模** - 例如：$XX Billion
- **增长率** - 例如：YoY +XX%
- **渗透率** - 例如：XX% 市场渗透

#### 4.3 行业趋势

**例如**：
- **技术趋势** - 例如：AI 技术普及、5G 网络
- **政策影响** - 例如：数据隐私法规、内容监管
- **需求变化** - 例如：用户行为变化、新消费场景

---

### 5. 竞争格局（Competition）

#### 5.1 主要竞争对手

**竞争对手表格**：

| 公司 | 产品 | 优势 |
|------|------|------|
| A公司 | XX | 市场份额高 |
| B公司 | XX | 技术领先 |
| C公司 | XX | 成本优势 |

#### 5.2 市场份额

**如有数据**：

| 公司 | 市占率 |
|------|--------|
| 市场领导者 | 30% |
| 本公司 | 20% |
| 其他 | 50% |

#### 5.3 竞争优势

**分析维度**：
- **技术** - 例如：专利、算法、研发能力
- **成本** - 例如：规模效应、供应链优势
- **渠道** - 例如：销售网络、合作伙伴
- **品牌** - 例如：知名度、用户忠诚度

---

### 6. 商业模式与财务（Business Model）

#### 6.1 收入模式

**例如**：
- **产品销售** - 一次性收费
- **订阅收费** - 月付/年付
- **平台抽成** - 交易佣金
- **广告收入** - CPM/CPC/CPA

#### 6.2 成本结构

**包括**：
- **研发** - R&D 投入
- **销售** - 营销和销售费用
- **生产** - 产品成本或运营成本

#### 6.3 财务表现

**关键指标表格**：

| 指标 | 数值 | YoY |
|------|------|-----|
| 收入 | $XX B | +XX% |
| 毛利率 | XX% | +X pp |
| 净利润 | $XX B | +XX% |
| 增长率 | XX% | - |

---

### 7. 战略与未来发展（Strategy）

**包括**：
- **公司战略** - 例如：全球化、多元化
- **产品规划** - 例如：新产品线、功能升级
- **市场扩张** - 例如：进入新市场、新用户群
- **新业务** - 例如：新业务板块、投资并购

---

### 8. 风险分析（Risk）

**可能风险**：
- **技术风险** - 例如：技术迭代、安全漏洞
- **市场风险** - 例如：竞争加剧、需求下降
- **政策风险** - 例如：监管变化、合规要求
- **竞争风险** - 例如：新进入者、替代品
- **运营风险** - 例如：人才流失、供应链问题

## 四类调研场景的结构权重表

不同的调研场景对报告章节的关注重点不同。根据调研目标，调整各章节的详细程度和顺序。

### 权重表说明

- **高** - 需要详细分析，作为报告重点
- **中** - 需要覆盖，适度详细
- **低** - 简要介绍或可以省略

### 结构模块权重对比表

| 结构模块 | 竞对分析 | 投资调研 | 客户调研 | 应聘调研 |
|---------|---------|---------|---------|---------|
| 0. Executive Summary | 高 | 高 | 高 | 高 |
| 1. 公司概况 | 中 | 中 | 低 | 高 |
| 2. 产品与业务 | 高 | 高 | 最高 | 中 |
| 3. 客户与市场 | 高 | 高 | 中 | 低 |
| 4. 行业分析 | 中 | 最高 | 低 | 低 |
| 5. 竞争格局 | 最高 | 高 | 中 | 低 |
| 6. 商业模式与财务 | 低 | 最高 | 低 | 低 |
| 7. 战略与未来发展 | 高 | 高 | 中 | 中 |
| 8. 风险分析 | 中 | 高 | 中 | 低 |
| 9. 综合评价 | 高 | 高 | 高 | 中 |

**使用说明**：
- **最高权重章节**应放在报告前面，详细分析
- **高权重章节**需要完整覆盖
- **中权重章节**简要介绍，突出重点
- **低权重章节**可以合并或省略

## 四类调研的典型逻辑

每种调研场景都有其核心问题和结构重点。

### 1. 竞对分析（Competitive Analysis）

**核心问题**：
> 对手在哪些方面比我强？

**典型结构**：
1. 公司概况
2. 产品体系
3. 技术能力
4. 客户结构
5. 商业模式
6. 市场份额
7. 优劣势分析

**重点章节**：
- **产品与业务**（最高权重）
- **竞争格局**（最高权重）
- **客户与市场**（高权重）

**关键问题**：
- 对手的核心产品是什么？
- 对手的技术优势在哪里？
- 对手的客户有哪些？
- 对手的市场份额如何？
- 对手的差异化策略是什么？

**输出重点**：
- 产品对比分析
- 技术能力评估
- 市场威胁程度
- 应对建议

---

### 2. 投资调研（Investment Research）

**核心问题**：
> 这家公司未来值多少钱？

**典型结构**：
1. 公司概况
2. 行业与市场
3. 商业模式
4. 财务分析
5. 增长逻辑
6. 竞争壁垒
7. 风险

**重点章节**：
- **行业分析**（最高权重）
- **商业模式与财务**（最高权重）
- **战略与未来发展**（高权重）

**关键问题**：
- 市场空间有多大？（TAM/SAM/SOM）
- 收入模式是什么？可持续吗？
- 增长驱动因素是什么？
- 有哪些竞争壁垒？
- 主要风险是什么？

**输出重点**：
- 投资逻辑
- 增长潜力
- 估值判断
- 风险评估
- 投资建议

---

### 3. 客户调研（Customer Research / Due Diligence）

**核心问题**：
> 这家公司是否值得合作？

**典型结构**：
1. 公司背景
2. 产品能力
3. 技术实力
4. 典型客户
5. 交付能力
6. 服务能力
7. 风险

**重点章节**：
- **产品与业务**（最高权重）
- **客户与市场**（中权重，侧重客户案例）

**关键问题**：
- 产品能否解决我们的痛点？
- 技术是否可靠？
- 有哪些客户案例？
- 服务和支持能力如何？
- 是否有实施风险？

**输出重点**：
- 适用性评估
- 产品能力分析
- 客户案例验证
- 集成和实施建议
- 合作风险评估

---

### 4. 应聘调研（Job Research）

**核心问题**：
> 这家公司适不适合我？

**典型结构**：
1. 公司发展阶段
2. 创始团队
3. 核心业务
4. 商业模式
5. 文化氛围
6. 组织结构
7. 职位发展

**重点章节**：
- **公司概况**（高权重，特别是团队和文化）
- **产品与业务**（中权重，了解业务）
- **战略与未来发展**（中权重，职业发展空间）

**关键问题**：
- 公司处于什么阶段？稳定吗？
- 创始团队和领导层怎么样？
- 公司文化是什么？
- 技术栈是什么？符合我的技能吗？
- 薪酬福利如何？
- 职业发展空间如何？

**输出重点**：
- 综合推荐指数
- 文化匹配度
- 技术匹配度
- 发展机会
- 注意事项
- 面试准备建议

## 数据质量评估标准

### 完整性评估

**高完整性**（90%+）：
- 所有必需章节都有数据
- 关键指标都有具体数值
- 多个数据源相互验证

**中等完整性**（70-89%）：
- 主要章节有数据
- 部分关键指标缺失
- 需要推断或估算

**低完整性**（<70%）：
- 多个章节缺失数据
- 大量关键指标缺失
- 数据来源单一

### 准确性评估

**高准确性**：
- 数据来自官方网站或权威来源
- 数据有时间戳
- 多个来源相互验证

**中等准确性**：
- 数据主要来自官网
- 部分数据需要推断
- 有限的外部验证

**低准确性**：
- 数据来源不明
- 大量推测
- 无法验证

### 时效性评估

**新鲜数据**（< 7 天）：
- 最近一周内爬取
- 适用于快速变化的行业

**近期数据**（7-30 天）：
- 一个月内爬取
- 适用于稳定行业

**较旧数据**（> 30 天）：
- 超过一个月
- 建议更新数据

## 报告生成流程

### Step 1: 识别调研场景

根据用户需求识别场景：
- **竞对分析** - 用户提到"竞品"、"竞争对手"、"对比分析"
- **投资调研** - 用户提到"投资价值"、"估值"、"值得投吗"
- **客户调研** - 用户提到"合作"、"供应商"、"评估"
- **应聘调研** - 用户提到"工作"、"应聘"、"公司文化"

### Step 2: 根据场景选择重点章节

参考结构权重表，确定：
- 哪些章节需要详细分析（高/最高权重）
- 哪些章节简要介绍（中权重）
- 哪些章节可以省略（低权重）

### Step 3: 调整报告结构顺序

将最重要的章节放在前面（Executive Summary 之后）。

### Step 4: 填充场景特定内容

参考典型逻辑，确保覆盖关键问题。

### Step 5: 撰写 Executive Summary

最后撰写 Executive Summary（虽然放在最前面），总结整个报告的核心结论。

## Anti-Patterns（避免错误）

### 报告撰写

- **NEVER** 混淆不同场景的关注重点 - 竞对分析不是投资调研
- **NEVER** 忽略 Executive Summary - 这是读者最关注的部分
- **NEVER** 使用不确定的语言 - "可能"、"大概"要避免
- **NEVER** 缺少数据来源 - 所有数据必须标明来源
- **NEVER** 忽略风险分析 - 每种场景都有特定的风险点

### 场景选择

- **NEVER** 在竞对分析中过度关注财务 - 市场和产品更重要
- **NEVER** 在投资调研中忽视商业模式 - 这是估值基础
- **NEVER** 在客户调研中忽略交付能力 - 能否落地很关键
- **NEVER** 在应聘调研中忽视文化匹配 - 这决定长期发展

### 数据质量

- **NEVER** 使用过时数据而不标注时间
- **NEVER** 推测关键数据而不说明
- **NEVER** 忽略数据质量评分
