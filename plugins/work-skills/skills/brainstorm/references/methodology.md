# 发散方法论

本文档为发散透镜库提供方法论支撑。所有方法论的共同指向：**撑开可能性空间**。任何用于评估、比较、决策的方法论不属于本技能。

---

## SCAMPER（奔驰法）

对现有想法做系统性变换，从一条分支拧出多条变体。

### 七个变换操作

| 字母 | 操作 | 核心问题 |
|------|------|---------|
| **S** - Substitute 替代 | 替换某个要素 | 换个成分/材料/流程/人会怎样？ |
| **C** - Combine 合并 | 与其他想法组合 | 能和哪条分支合并成新东西？ |
| **A** - Adapt 借用 | 从别处挪用 | 别的领域有什么可以被借来这里？ |
| **M** - Modify/Magnify 修改/放大 | 放大或缩小某要素 | 把这个特性放大 10 倍/缩小到极致？ |
| **P** - Put to another use 挪用 | 换用途 | 这个想法换个场景还能干什么？ |
| **E** - Eliminate 消除 | 删减 | 去掉最核心的要素后会剩下什么？ |
| **R** - Reverse/Rearrange 逆向/重排 | 反转或重排 | 把流程倒过来/角色互换会怎样？ |

### 应用要点

- 每次 SCAMPER 至少遍历 5 个操作，每个操作至少产出 1 个变体
- 变体不评判优劣，全部记入分支地图
- 最肥沃的操作通常是 **E（消除）** 和 **R（逆向）**——它们破坏隐含假设

### 来源

Alex Osborn（头脑风暴之父）首创清单，Bob Eberle 整理为 SCAMPER 缩写。

## 爱德华·德·波诺 - 水平思维（Lateral Thinking）

### 核心原则

**打破思维定式**："将同一个洞挖深，并不能挖出一个新的洞。" 水平思维是横向开挖新洞，不是纵向深挖旧洞。

### 绿帽思考（本技能唯一采用的帽子）

六顶思考帽中，绿帽是唯一的纯创造帽：
- 只产生新想法和可能性，**不批评**
- 核心问题："还有什么可能？""能否换个方式？"
- 允许"provocation（激发）"：故意提出不合理的陈述再从中提取价值

> 本技能**不使用**黑帽（风险）、黄帽（价值评估）、蓝帽（流程控制）——它们都是评估/收敛工具。白帽（事实）仅作为检索燃料的描述方式使用。

### 水平思维激发技巧

**1. 随机输入法（Random Entry）**
- 随机选一个无关词/物体/概念
- 强制建立与当前话题的关联
- 例："集装箱" × "在线教育" → 标准化封装的课程单元，可堆叠组合

**2. 概念抽取（Concept Extraction）**
- 从一个现有想法中抽取抽象概念
- 把概念当种子，长出全新分支
- 例："网约车" → 抽取"闲置资源 + 即时匹配" → 闲置算力撮合平台

**3. 挑战假设（Challenge Assumptions）**
- 列出想法背后的所有隐含假设
- 逐条质问："为什么必须这样？"
- 这是逆向假设透镜的方法论基础

### 来源

爱德华·德·波诺：《水平思维》（*Lateral Thinking*）、《六顶思考帽》（*Six Thinking Hats*）、《严肃创造力》（*Serious Creativity*）

## 第一性原理（First Principles Thinking）

### 在本技能中的定位

第一性原理在本技能中**只用于一个方向**：拆掉假设，为重构可能性开路。它不是用来"寻找最优解"的（那是收敛）。

### 使用模板

1. 写下当前想法的固有假设（"大家一直这么做"的部分）
2. 质疑："这个假设物理上/逻辑上必须成立吗？"
3. 把想法分解到基本要素
4. **从要素出发重新组合**——注意：组合出的所有形态都记录，不筛选

### 经典案例（注意：案例本身展示的是"拆假设"的发散威力）

**特斯拉电池成本**：类比思维说"电池一直很贵"；第一性原理拆到钴、镍、铝、碳的材料成本，发现市场价远高于材料价——假设被拆掉后，"自建电池厂""换电池化学体系"等新分支才成为可见选项。

**SpaceX 火箭成本**：拆到材料成本仅占火箭价格 2%——"火箭必须一次性使用"的假设塌了，"回收复用"分支才出现。

## 查理·芒格 - 多元思维模型（作为类比燃料库）

### 在本技能中的定位

芒格的跨学科模型清单在本技能中**只当燃料用**：为"类比跨界"透镜供给其他领域的视角。不做"综合判断"（那是收敛）。

### 高频可借用的模型域

**生物学/生态学**：共生（互利/偏利/寄生）、生态位、共生演化、冗余备份
**经济学**：边际效应、规模效应、网络效应、激励结构、双边市场
**心理学**：损失厌恶、社会认同、稀缺性、习惯回路、心流
**系统论**：正反馈环、负反馈环、延迟效应、涌现
**军事/博弈**：不对称作战、威慑、消耗战 vs 机动战

### 使用方式

问自己："这个模型域里有没有结构上相似的现象？"——然后只做一件事：**把它翻译成用户话题里的一个新分支**，不评估该分支是否可行。

### 来源

查理·芒格：《穷查理宝典》

## 经典头脑风暴四原则（宪法条款来源）

Alex Osborn, *Applied Imagination* (1953)：

1. **延迟评判**（Defer Judgment）：评判与生成分离，生成阶段零评判
2. **追求数量**（Go for Quantity）：数量是质量的先决条件
3. **鼓励狂野**（Encourage Wild Ideas）：夸张的想法可以拉宽可能性空间，事后收缩容易，事前拓宽难
4. **搭便车组合**（Build on Ideas）：在已有想法上叠加、组合、延伸

## 已移除的方法论（及原因）

以下方法论原属本技能，因**收敛导向**与纯发散定位冲突而移除：

- **ORID 焦点讨论法**：终点是 Decisional（决策），是漏斗不是发散器
- **GROW 模型**：整体导向行动方案（Will），纯教练式收敛工具
- **五个为什么**：根因分析，指向"针对性解决方案"，是收敛
- **彼得·圣吉杠杆点分析**：找"牵一发动全身"的干预点，是系统分析的收敛动作
- **六顶思考帽（黑/黄/蓝帽）**：风险评估、价值评估、流程控制，均为收敛力
