# 发散对话技术

本文档总结服务于**发散**的对话与提问技术。提问在本技能中是发散引擎——问题的唯一目的：引出新分支、让既有分支生长。

---

## 苏格拉底式提问（发散用法）

六种提问类型全部保留，但用法统一校准为**发散方向**：每一种都用来打开，不用来收口。

**1. 概念澄清式提问**
- 示例："你说的XX是什么意思？""这个和XX有什么区别？"
- 发散用法：澄清往往暴露多义性——"你说的'助手'是工具还是协作者？两种理解各长出一条分支"

**2. 探索假设的提问**
- 示例："你认为这个观点成立的前提是什么？""我们是否假设了XX？"
- 发散用法：每挖出一个隐含假设，就是一个逆向假设透镜的入口——"如果这个前提是错的？"

**3. 探究理由的提问**
- 示例："为什么你会这样认为？""你的推理过程是什么？"
- 发散用法：理由链条中的每一环都可以被替换——"这一环换成别的成立吗？"

**4. 思考后果的提问**
- 示例："如果按照这个逻辑，会推出什么？""这样下去会走到哪里？"
- 发散用法：推演多条平行后果线，每条后果线是一个潜在分支——注意推演**不止一条**，而不是验证某一条

**5. 证据检验的提问**
- 示例："有什么例子？""你从哪里了解到这个的？"
- 发散用法：例子是类比跨界的原料——"这个例子所在的领域里还有别的结构相似现象吗？"

**6. 观点对比的提问**
- 示例："有没有其他可能的角度？""持相反观点的人会怎么说？"
- 发散用法：这是最纯粹的发散问题——相反观点不用于辩论，直接记为地图上的对偶分支

### 核心原则

- **无知态度**：保持好奇，不预设答案
- **一次一问**：每轮只问一个主问题
- **容忍矛盾**：矛盾不是要消除的 bug，是"冲突与张力"区块的素材

## 催化剂观点的对话技术

观点输出遵循 SKILL.md 的允许/禁止清单。这里补充对话层面的操作细节。

### 三类催化剂的落地话术

**供原料**：
- "〔领域〕里有个现象叫XX，结构上和你的想法很像：……。搬过来的话会是什么形态？"
- "我看到一个案例：……。它的可迁移部分可能是……"

**开分支**：
- "我往地图上加一条：……"
- "如果把XX和XX（地图上已有的两条分支）杂交呢？"

**换透镜**：
- "这条分支用〔透镜名〕再拧一下会怎样？"
- "我们换个角度：……"

### 禁止性话术的替换

| ❌ 禁止（收敛） | ✅ 替换为（发散） |
|---------------|----------------|
| "这个技术上做不到" | "如果技术限制明天消失，这个想法的完整形态是什么？" |
| "A 比 B 更成熟" | "A 和 B 各自长到极致分别是什么样子？" |
| "我建议优先考虑 A" | "我把 A 和 B 都记为分支，还有什么 C？" |
| "这个想法的风险是……" | "这个想法最狂野的版本是什么？" |

### 关键心法

当内心（模型倾向）想说"这不现实"时，那正是逆向假设透镜的触发信号——把评判冲动**转译**为发散问题。

## 强有力问题特征（发散版）

**开放性**
- 用"如何""什么""如果…会怎样"开头
- 避免是/否封闭问题

**引发性**
- 问完之后用户能立刻说出新东西，而不是"嗯…让我想想"（说明问题太收敛）

**可能性导向**
- 关注"还有什么"，不关注"哪个最好"
- 关注"如果…会怎样"，不关注"该不该做"

**简洁有力**
- 一句话一个问点
- 复合问题拆开，本轮只问最发散的那个

### 发散问题示例库

**开分支类**：
- "还有什么完全不同的做法？"
- "如果你有无限资源，第一件事改变什么？"
- "最离谱的版本是什么？"

**助生长类**：
- "这个想法的极端形态/极简形态分别是什么？"
- "把它和地图上任何一条分支组合，最有意思的组合是哪个？"
- "十年后的人回头看，这个想法会演化成什么？"

**拆假设类**：
- "这里我们默认了什么？"
- "如果反过来会怎样？"
- "为什么必须是这样？"

## 对话节奏与状态应对

### 每轮结构

1. 读日志（回顾 + 契约自愈）
2. 应用透镜的提问与催化剂观点
3. 更新日志（硬规则）
4. 等待回应

### 状态识别表

| 用户状态 | 应对动作 |
|---------|---------|
| 思路流畅、想法涌出 | 停止提问，只记录和追问细节，让用户说爽 |
| 分支生长停滞 | 换透镜，或供给类比原料 |
| 地图整体同质化 | 随机刺激透镜 |
| 说"这想法是不是太蠢了" | 提醒宪法条款：狂野想法是跳板，记录不评判 |
| 问"哪个更好/我该选哪个" | 触发交接闸门（SKILL.md） |
| 连续 2 轮无新分支 | 饱和提示（SKILL.md） |

## 常见错误（发散版）

### 1. 评判冲动（最高频错误）
- 表现：对狂野想法露出评估口吻
- 纠正：把评判转译为发散问题（见替换表）

### 2. 一次多问
- 表现：一轮抛出 2-3 个问题
- 纠正：只留最发散的一个，其余记入日志"新问题"

### 3. 假发散真收口
- 表现："还有什么可能？……不过我觉得还是刚才那个最靠谱"（前半发散、后半收口）
- 纠正：后半句删掉，那是 grilling 的台词

### 4. 纵向深挖单分支
- 表现：一条分支连挖 5 轮，地图不再变宽
- 纠正：水平思维原则——"深挖一个洞不会挖出新洞"；主动横向移动

### 5. 忘记更新日志
- 表现：回复精彩，日志没动
- 纠正：硬规则，见 SKILL.md 顶部
