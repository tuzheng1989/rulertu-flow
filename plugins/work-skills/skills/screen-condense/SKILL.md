# 录屏自动精简

使用随包脚本离线处理录屏，输出无声 MP4 和源视频到成片的时间对应表。
优先复用脚本，避免每次重新实现画面分析和变速逻辑。

## 执行

1. 从当前对话取得源文件路径、目标时长和输出位置。只有缺少输入文件时才追问路径；
   未指定时长时默认 3 分钟，用户给出的时长优先。
   这是无声录屏流程；如果用户要求保留讲解或音轨，先解决音频需求再使用。
2. 确认源文件可读，选择可写的输出目录。默认使用当前工作区的 `output/`，
   输出命名为 `<源文件名>_<目标秒数>s.mp4`；同名文件存在时换一个新名称。
   脚本拒绝覆盖源文件、已有输出及同名时间对应表。
3. 检查 `python -c "import cv2, numpy"`。缺少依赖时，使用当前环境的安装方式安装
   [scripts/requirements.txt](scripts/requirements.txt)，不因本任务修改无关项目的依赖。
   Python 需要 3.10 或以上。所有随包路径均相对本 `SKILL.md` 所在目录解析。
4. 运行 [scripts/condense.py](scripts/condense.py)，替换下面命令中的路径和时长：

   ```powershell
   python "<skill目录>/scripts/condense.py" "<源视频绝对路径>" --seconds 180 -o "<输出绝对路径>.mp4"
   ```

   将路径作为单独的参数传递，兼容中文和空格。需要安装依赖时：

   ```powershell
   python -m pip install -r "<skill目录>/scripts/requirements.txt"
   ```

5. 跟踪同一个运行进程的进度。脚本依次分析、导出、完整解码校验；
   用户说“继续”时继续跟踪，不另起重复任务。
   失败时保留错误输出，定位原因后再重试；不要仅凭生成了文件就宣布成功。
6. 进程退出码为 0 后，检查 MP4 和同名 `.timeline.json` 均存在，
   对照报告中的实际输入、输出秒数。交付可点击的成片路径和实际时长。
   完整解码通过证明文件可读，不等于每个业务操作都得到保留。

## 调整与边界

- 脚本用画面变化估计活动，在变化前后留出上下文，并为开头、结尾分配更多时间。
  它保持操作顺序，通过抽帧实现变速，不识别操作含义、错误步骤或重复步骤。
- 目标时长优先。操作密集时活动片段也会加速；输入短于目标时不补长，
  输出时长按一帧取整。报告使用实测输入时长，不能直接沿用用户的估计。
- 细小文字输入或局部变化被掠过时，可降低 `--threshold`，例如使用 `0.0003`，
  并导出到新文件供比较。动画、进度条和闪烁光标也可能被视为活动。
  其他参数以脚本 `--help` 为准。
- 适合固定帧率录屏；可变帧率输入按平均 FPS 估算，时间可能偏移。
  用户要求精确时间对齐时，先用可用的转码工具生成固定帧率副本。
- 输出不保留音轨，尺寸保留到偶数像素。编码为 MPEG-4 Part 2；用户需要浏览器
  或平台兼容性时，再按需用 FFmpeg 转成 H.264，完成转码后校验实际交付文件。
- 全程本地计算。依赖安装可能联网；视频分析本身不需要账号、模型或外部 API。
