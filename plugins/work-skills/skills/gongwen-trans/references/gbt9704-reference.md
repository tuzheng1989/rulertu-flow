# GB/T 9704-2012 党政机关公文格式速查

## 页面设置

| 项目 | 规格 |
|------|------|
| 纸张 | A4 (210mm × 297mm) |
| 天头（上白边） | 37mm ± 1mm |
| 地脚（下白边） | 35mm ± 1mm |
| 订口（左白边） | 28mm ± 1mm |
| 翻口（右白边） | 26mm ± 1mm |
| 版心（正文区域） | 156mm × 225mm |
| 每页行数 | 22 行 |
| 每行字数 | 28 字 |

## 字体规范

| 公文要素 | 字体 | 字号 | 行距 | 对齐 |
|---------|------|------|------|------|
| 标题 | 方正小标宋简体 | 二号 (22pt) | — | 居中 |
| 发文字号 | 楷体 | 三号 (16pt) | — | 居中 |
| 主送机关 | 仿宋 | 三号 (16pt) | 固定 28pt | 左对齐，顶格 |
| 正文 | 仿宋 | 三号 (16pt) | 固定 28pt | 两端对齐，首行缩进 2 字符 |
| 一级标题 | 黑体 | 三号 (16pt) | 固定 28pt | 左对齐，首行缩进 2 字符 |
| 二级标题 | 楷体 | 三号 (16pt) | 固定 28pt | 左对齐，首行缩进 2 字符 |
| 三级标题 | 仿宋加粗 | 三号 (16pt) | 固定 28pt | 左对齐，首行缩进 2 字符 |
| 附件说明 | 仿宋 | 三号 (16pt) | 固定 28pt | 左对齐，首行缩进 2 字符 |
| 发文机关署名 | 仿宋 | 三号 (16pt) | — | 右对齐 |
| 成文日期 | 仿宋 | 三号 (16pt) | — | 右对齐 |
| 抄送 | 仿宋 | 四号 (14pt) | — | 左对齐 |
| 页码 | 宋体 | 四号 (14pt) | — | 居中 |

## 层级标题编号规则

| 级别 | 编号格式 | 示例 |
|------|---------|------|
| 一级 | 中文数字 + 顿号 | 一、二、三、 |
| 二级 | 中文数字 + 括号 | （一）（二）（三） |
| 三级 | 阿拉伯数字 + 点 | 1. 2. 3. |
| 四级 | 阿拉伯数字 + 括号 | （1）（2）（3） |

## 公文要素排列顺序

```
版头区域：
  发文机关标志（红头）
  发文字号
  ─── 红线 ───

主体区域：
  标题
  主送机关
  正文
  附件说明
  发文机关署名
  成文日期
  附注

版记区域：
  抄送机关
  印发机关 + 印发日期
```

## Windows 字体映射

| 标准字体 | Windows 注册表名称 | TTF 文件 |
|---------|-------------------|---------|
| 方正小标宋简体 | FZXiaoBiaoSong (通常未安装) | — |
| 仿宋 / 仿宋_GB2312 | FangSong | simfang.ttf |
| 楷体 / 楷体_GB2312 | KaiTi | simkai.ttf |
| 黑体 | SimHei | simhei.ttf |
| 宋体 | SimSun | simsun.ttc |

> 方正小标宋简体未安装时，标题使用宋体 (SimSun) + 加粗作为替代。
