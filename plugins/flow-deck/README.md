# flow-deck

Claude Code 的工作流、Git 与子代理状态面板。Codex manifest 仅提供占位元数据。

安装：`/plugin install flow-deck --marketplace tuzheng1989/rulertu-flow`。

- `/flow` 开关当前任务面板：方案迭代时显示当前方案的评分、分差与 P0/P1/P2（达标方案折叠为一行）；实施时显示极简阶段进度条（比例条 + 当前阶段名与序号）、验证进度、批次边界和执行 DAG（按批着色的分段总览条 + 依赖树）。实施上报超 30 分钟未续报时显示"疑似停滞"提示。无任务时提示"当前无方案迭代或实施任务"，并显示跨会话恢复的上次执行摘要。面板内按 `r` 重取评审、git 与子代理数据。
- `/git` 开关仓库面板：分支与上下游差异、行数变化、冲突及暂存/未暂存/未跟踪文件；每类最多展示 15 条，长路径保留两端。
- `/doc` 开关文档浏览面板：`/doc <相对路径>` 装载文档，按节浏览（Select 选节，节内超 60 行截断显示，草稿行号仍用全节范围）；按 `e` 把「请修改 <路径> 的「<节标题>」一节（第 a–b 行）」填入输入框草稿（已有草稿时追加，不覆盖），人补完意图回车后走正常 Edit/Write 链路，批次守卫继续生效。无路径时已开则关、未开给用法；读取失败或空文档面板内提示，按 `r` 重读。fenced code block 内的 `#` 不算节标题。
- 子代理状态并入工作流面板：面板底部的常驻区块显示当前会话的运行中 / 已完成 / 失败 / 已停止数量，以及每个代理的名称、任务描述、类型、ID、父代理和来源插件；运行中优先，保留宿主未知状态的原文，避免把等待或空闲误判为完成。`/flow-agents` 幂等打开工作流面板（已开时提示而不关闭），保留宿主自带的 `/agents` 管理入口。引擎的面板为标签页模型：同刻只显示一个面板，其余为标签页（Tab 切换）；面板位置由宿主决定——全屏 transcript 且终端不窄于 110 列时停靠在消息旁，否则内联在输入框上方（inline 高度可拖拽调整并被记住）。
- 输入区上方最多占两行，遵守宿主可用行数；仅容一行时冲突优先，其次当前执行。达标评审仍从 statusline 撤下，通过 toast 通知。

`flow_task` 声明当前任务（`kind: iterate | implement | idle`，活动任务必填 `plan`，实施可附 `batch`）；plan-iterate 与 implement-plan 技能在开始和结束时同步任务。`flow_report` 的未收口阶段、`flow_batch` 声明也会激活对应实施批次；批次收口或 `idle` 后撤下执行显示与边界守卫。暂停、取消或失败停止时上报 `idle`，恢复时重新声明任务。warn 越界提醒按文件去重，同批同文件只提醒一次（批次重新声明后重置），文案含触发工具名。

历史评审文件、`flow_deps` 路线图和跨会话执行记录不激活任务；新会话从无任务状态开始，上次执行仅通过 toast 提醒。依赖图只在实施对应方案时显示。更新时同时更新 flow-deck 与 rulertu-flow，以加载配套的任务上报规则。

上报数据直接更新界面，无动画计时器或新增依赖。终端与桌面共用 Text / Box，窄于 44 列时去掉卡片边框。

子代理清单读取宿主的 `$.agent.list()`，覆盖当前会话的子代理与进程内队友，不依赖工作流任务声明。仅面板打开时查询，打开后立即刷新，此后复用现有 2 秒轮询；关闭后停止查询（已发出的查询可能完成），相同快照不重复写状态。查询失败保留上次快照并提示可能已过期，自动重试；新会话清空旧快照。该接口未提供开始时间、token 用量、工具日志或外部 CLI 进程状态，面板只展示宿主返回的数据。

轮询开销与时效：

| 数据 | 刷新策略 |
| --- | --- |
| 已知评审目录 | 每 2 秒列目录；文件名、大小与修改时间不变时复用解析结果 |
| 新 `.plan-iterate` 根目录 | 启动时发现，此后每 30 秒搜索，最多四层；跳过依赖、构建目录 |
| Git 有文件改动 | 每 5 秒查询 status，仅对有 tracked 改动的一侧查询 diff 行数 |
| Git 无文件改动 | 每 15 秒仅查询 status；无上游偏差时隐藏横条 |
| 非仓库或 Git 查询失败 | 每 60 秒重试；打开 `/git` 会立即异步重查 |
| 子代理 | `/flow` 打开时每 2 秒读宿主清单；关闭时不查询，无进程或文件扫描 |

相同快照不重复写插件状态；定时轮询与手动刷新共享防重入查询。以稳定干净仓库计算，Git 调用由每分钟约 60 次降至 4 次；这是调用次数估算，实际 CPU / I/O 取决于仓库规模。新评审根目录的首次展示可能延迟至 30 秒。

验证：`claude plugin test plugins/flow-deck`、`claude plugin validate plugins/flow-deck`（从仓库根运行）。测试覆盖任务切换与结束、历史数据过滤、边界撤销、缓存、发现延迟、文件变化、Git 分侧查询、退避与防重入、子代理状态变化与失败恢复、面板合并与幂等打开、阶段进度条、DAG 分色总览条、达标折叠、空态面包屑、停滞检测与刷新按钮、文档面板装载与选节、修改请求草稿填入（空/非空草稿分流）、parseSections 标题切分与围栏跳过，以及终端/桌面宽窄面板的渲染树；实际宿主绘制仍需在 Claude Code 中查看。
