## 模式两两对比（决策点）

- **协调器-子代理 vs 代理团队**：工作成员需维护上下文多久？短暂专注用前者，持续多步骤用后者。
- **协调器-子代理 vs 消息总线**：工作流可预测吗？步骤预先已知用前者，事件涌现用后者。
- **代理团队 vs 共享状态**：代理需要彼此发现吗？独立分区用前者，协作共享用后者。
- **消息总线 vs 共享状态**：工作离散流动还是累积？对事件反应用前者，知识累积用后者。

各模式的适用场景、常见陷阱、扩展变体详见对应文件。
