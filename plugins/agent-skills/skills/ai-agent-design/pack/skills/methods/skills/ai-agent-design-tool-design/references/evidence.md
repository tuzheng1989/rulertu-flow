# evidence · 工具设计
来源：bojieli/ai-agent-book

## 核心证据
- **ch4 整章**：工具设计决定能力上限，异步架构决定可靠性；ACI 原则；MCP 互操作；五类工具（感知 / 执行 / 协作 / 事件触发 / 用户沟通）；执行工具的提议者-审核者 + Sidecar；异步 Agent（OpenClaw Hooks/Cron/Heartbeat → PineClaw Channel）；主动工具发现；参数传递保真性底线。
- **ch5**：代码是通用性最强的工具（元能力），工具设计原则可推广到「创造工具」。

## 多语境支持
ch4（工具设计 + 异步架构）+ ch5（代码作为元工具）两个独立章节支撑。

## 迁移性
五类工具设计要点与 ACI 原则适用于任何 Agent 工具生态；MCP 互操作对跨厂商工具集成通用。
