# evidence · SFT vs RL 选型
来源：bojieli/ai-agent-book

## 核心证据（ch7 多节独立支撑）
- **07.04 SFT 监督微调**：用标注数据教模型照样学样。
- **07.05 何时选择 SFT、何时选择 RL**：直接给出选型决策。
- **07.06 单轮强化学习——记忆与泛化的对照**：「SFT 记忆、RL 泛化」可测量现象。
- **07.07 RLHF**：从人类偏好到奖励模型。
- **07.08 强化学习算法比较**：算法选择不是关键。
- **07.09 数据与环境比算法更重要**：差距在仿真保真度与数据质量。
- **07.10 从单轮到多轮——信用分配与奖励设计**。
- **07.11 RL 学习工具调用**；**07.12 样本效率前沿**（On-Policy Distillation）；**07.13 后训练完整图景**。

## 证据范围说明
方法证据集中在 ch7 单章（多节独立支撑，是该方法的天然归属章）。满足「多语境证据」的方式是章内多节 + 作者自有论文（RLVP, Li & Shi 2026）。

## 迁移性
选型决策与奖励演进路径适用于任何 Agent 后训练；「数据环境 > 算法」「样本效率瓶颈」是跨场景判断。
