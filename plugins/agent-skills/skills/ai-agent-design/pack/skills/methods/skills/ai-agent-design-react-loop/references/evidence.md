# evidence · ReAct 循环
来源：bojieli/ai-agent-book

## 核心证据
- **ch1 / 01.01「现代 Agent = LLM + 上下文 + 工具」**：ReAct 循环的本质是通过不断追加轨迹让模型持续推进任务；上下文消融实验证明各组件必要。
- **ch2 / 02.02「Agent 如何调用大模型」**：API 消息结构定义上下文骨架；Agent 核心循环剖析；生产代码需 max_iterations 上限，否则 Agent 会重复调用同一工具陷入死循环。
- **ch4 实验 4-1~4-3**：实现感知 / 执行 / 协作工具的 ReAct 循环。

## 多语境支持（≥2 独立章节）
ch1（定义）+ ch2（API 实现）+ ch4（工具调用实验）= 三个独立章节支持同一方法。

## 迁移性
适用于任何需要「自主决策 + 工具调用 + 基于结果继续」的 Agent 场景，不局限于书中实验领域。
