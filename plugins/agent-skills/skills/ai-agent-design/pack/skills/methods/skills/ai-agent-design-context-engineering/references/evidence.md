# evidence · 上下文工程
来源：bojieli/ai-agent-book

## 核心证据
- **ch2 / 02.01~02.07**：上下文决定能力上限；API 消息结构、KV Cache 友好设计、提示工程、Agent Skills 按需加载、状态栏、上下文压缩策略。共同点：显式、工程化的知识管理。
- **ch2 结语**：呼应 Sutton《苦涩的教训》——能更有效利用算力的通用方法最终胜出。
- **ch3**：跨会话上下文管理（双层记忆架构），与 ch2 同属上下文支柱、收敛为同一套技术。

## 多语境支持
ch2（单会话）+ ch3（跨会话）两个独立章节共同支撑「上下文工程」这一方法族。

## 迁移性
五项技术可独立或组合用于任何 LLM Agent 的上下文优化；KV Cache 友好性对所有按前缀缓存的主流推理引擎通用。
