# evidence · 评估驱动迭代
来源：bojieli/ai-agent-book

## 核心证据
- **引言**：「没有评估，就没有进步」；要赶在名词流行前掌握原则，必须①拥有高要求真实业务 ②建立评估机制。评估是科学方法论的地基。
- **ch6 整章**：观察→假设→实验→验证闭环；评估环境→数据集→LLM-as-a-Judge/Rubric→Benchmark 分析→系统改进→更新，形成完整闭环；评估是 Harness「验证」功能的系统化实现。
- **ch7**：评估环境与数据集是后训练的重要输入，仿真环境是练习场（评估到后训练的桥梁）。

## 多语境支持
引言（原则）+ ch6（方法论语）+ ch7（作为后训练输入）= 三处独立支撑。

## 迁移性
适用于任何 Agent / LLM 系统的迭代改进；「统计显著性判断改动真伪」对所有工程实验通用。
