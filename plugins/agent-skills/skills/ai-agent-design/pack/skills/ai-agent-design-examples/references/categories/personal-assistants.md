# 👤 Personal Assistants

> AI agents that can act as personal assistants

共 2 个项目（按 GitHub Stars 降序，无 stars 者按名称）。

### LiveRecall
- 描述：LiveRecall, an open-source alternative to Microsoft's Recall, utilizes semantic search and encryption to capture and retrieve screen snapshots, enabling AI agents to assist creators in researching and augmenting tasks like journaling or blog post creation based on indexed personal activities
- 开源：✅ 开源
- 链接：[GitHub](https://github.com/VedankPurohit/LiveRecall)

### OpenRecall
- 描述：OpenRecall is an open-source, privacy-focused digital memory tool capturing and indexing screenshots to enhance productivity without compromising privacy, usable across Windows, macOS, and Linux, and compatible with AI agents for personal assistance
- 开源：✅ 开源
- 链接：[GitHub](https://github.com/openrecall/openrecall) · [Discord](https://discord.gg/RzvCYRgUkx) · [Telegram](https://t.me/+5DULWTesqUYwYjY0)
