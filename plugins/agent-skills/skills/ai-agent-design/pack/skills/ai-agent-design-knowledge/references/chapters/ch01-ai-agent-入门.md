# 第 1 章 · AI Agent 入门

> 来源：原书第 1 章（全书框架章）。衍生解释，非逐字原文。

## 核心问题
Agent 是什么？由哪些部分组成？为什么 Harness 才是竞争力？

## 核心观点
- **Agent = 大脑 + 眼睛 + 手脚**：LLM（决策）+ 上下文（能看到什么）+ 工具（能做什么）。
- **眼睛（上下文）是决定性因素**：上下文 = 静态前缀（系统提示词 + 工具定义）+ 动态轨迹（消息历史）。消融实验表明去掉任一组件系统显著退化。
- **ReAct 循环**：思考→行动→观察的迭代；本质是不断追加轨迹让模型持续推进任务。
- **Harness 是竞争力**：模型能力商品化，差异在 Harness（约束 / 验证 / 纠正机制）。生产级 Agent 大部分代码是保障机制，而非上下文与工具本身。
- **安全是架构问题**：护栏、人工干预、对齐（alignment）从第一行代码就要考虑；贯穿模型 / 上下文 / 工具 / 协作 / 社会五个层面。

## 关键概念
- **Harness**：模型之外的工程脚手架（约束、验证、纠正）。
- **ReAct**：Reasoning + Acting 循环。
- **编排顺序**：先优化提示词 → 再工作流 → 最后才引入自主 Agent（降低意外风险的最实用顺序）。
- **编排模式**：链式 / 并行 / 路由 / 编排者-工作者 / 评估器-优化器，各有适用场景，无通用最优。
- **对齐 alignment**：让模型行为与人类意图一致。

## 论证与证据
- 上下文消融实验证明各组件必要性。
- 多个真实 Agent 产品（Manus、Claude Code、OpenClaw、Pine）印证「代码生成 + 文件系统」范式。

## 权衡与反例
- 不存在通用最优编排模式，自主 Agent 风险高于工作流，需按顺序引入而非一步到位。
