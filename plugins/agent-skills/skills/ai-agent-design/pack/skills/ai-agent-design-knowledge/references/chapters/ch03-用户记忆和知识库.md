# 第 3 章 · 用户记忆和知识库

> 来源：原书第 3 章。衍生解释，非逐字原文。

## 核心问题
Agent 如何跨会话记住用户、接入外部知识，成为领域专家？

## 核心观点
本章把上下文管理从单次会话延伸到跨会话持久化，分两个尺度：**用户记忆**（针对个体）与**共享知识库**（面向所有用户）。二者最终收敛为同一套技术。

## 用户记忆：四种渐进式策略
从原子化事实到情境化知识管理，揭示**简单性 vs 表达力**的根本张力：
- Simple Notes → … → Advanced JSON Cards。
- 工程化框架：Mem0、Memobase；隐私保护机制贯穿全流程。

## 知识获取（RAG 技术栈）
文档分块划定检索单元 → 稠密嵌入捕捉语义 → 稀疏嵌入做关键词匹配 → 结果融合汇成候选池 → 神经重排序作最终精排 → 以 recall@k 度量检索质量。多模态把感知扩展到图表与文档版式。

## 知识理解（超越扁平分块）
- **RAPTOR**：树状层次摘要。
- **GraphRAG**：实体关系网络。
- **上下文感知检索**：从根本上解决语义丢失。
- **Agentic RAG**：从被动「检索-生成」管道，转向 Agent 主导的主动迭代探索（自主决定何时检索、检索什么）。

## 双层记忆架构（核心收敛结论）
Advanced JSON Cards **常驻上下文**提供「概览」+ 上下文感知检索**按需**提供「细节」，二者叠加显著提升跨会话召回精度与冲突解决能力，支撑「主动服务」。

## 权衡与反例
- 简单记忆表达力弱；复杂结构维护成本高——张力始终存在。
- 扁平分块丢失语义结构，需层次化 / 图谱化补偿。
