# 术语表（Glossary）

> 全书关键术语，含作者特有区分。格式：术语 — 释义（出处章）。衍生解释。

## ⚠️ 作者特有术语区分（务必注意）
- **思考（reasoning）** — 模型展开中间推导、「想」的过程；含思维链 CoT、思考模型（o 系列 / DeepSeek-R1）、思考 token。（全书）
- **推理（inference）** — 模型前向计算与部署运行；推理时 / 推理成本 / 推理时扩展。（全书）
- **例外**：逻辑推理、多跳推理、空间推理、时序推理仍用「推理」（指演绎推断，非 inference）。

## 核心概念
- **Agent = LLM + 上下文 + 工具** — 核心公式；直觉层=大脑+眼睛+手脚，学术层=Policy+Observation+Action。（引言/ch1）
- **Harness** — 模型之外的工程脚手架（约束 / 验证 / 纠正机制）；模型商品化时代的竞争力所在。（ch1）
- **ReAct** — Reasoning+Acting，思考→行动→观察的迭代循环。（ch1）
- **对齐（alignment）** — 让模型行为与人类意图一致。（ch1）

## 上下文（ch2-3）
- **KV Cache** — 推理中复用历史计算；前缀稳定才能命中，约束上下文布局。（ch2）
- **提示注入（Prompt Injection）** — 对提示词的攻击。（ch2）
- **Agent Skills** — 动态按需加载的提示词，解决提示词无限膨胀。（ch2）
- **状态栏** — 用 user 角色承载元信息（环境 / 任务进度 / 用户状态）。（ch2）
- **上下文压缩** — 主动总结把原始数据变高密度结构化知识。（ch2）
- **用户记忆四策略** — Simple Notes → Advanced JSON Cards 的渐进式。（ch3）
- **RAG** — 检索增强生成。（ch3）
- **Agentic RAG** — Agent 主导主动迭代检索。（ch3）
- **RAPTOR** — 树状层次摘要索引。（ch3）
- **GraphRAG** — 实体关系网络索引。（ch3）
- **双层记忆架构** — JSON Cards 常驻概览 + 上下文感知检索按需细节。（ch3）

## 工具（ch4-5）
- **MCP** — Model Context Protocol，工具互操作标准。（ch4）
- **ACI** — 工具设计通用原则（粒度 / 通用性 / 描述）。（ch4）
- **提议者-审核者（proposer-reviewer）** — 事前审批 + 事后验证的执行安全机制。（ch4）
- **Sidecar** — 执行工具的旁路机制。（ch4）
- **参数传递保真性** — 模型感知世界与工具操作世界不能有系统性偏差。（ch4）
- **Channel 机制** — PineClaw 事件驱动接入。（ch4）
- **元能力** — 代码作为思考语言 + 创造工具的工具。（ch5）

## 模型（ch6-7）
- **LLM-as-a-Judge** — 用 LLM 担任评估评判者。（ch6）
- **Rubric** — 评分量规。（ch6）
- **SFT（监督微调）** — 用标注数据教模型照样学样；「记忆」。（ch7）
- **RL（强化学习）** — 试错 + 奖励反馈自主提升；「泛化」。（ch7）
- **RLHF** — 基于人类反馈的 RL。（ch7）
- **PRM（过程奖励模型）** — 逐步验证的过程奖励。（ch7）
- **RLVP** — 奖励结果、惩罚路径（作者提出）。（ch7）
- **On-Policy Distillation** — 密集信号提升样本效率。（ch7）
- **VLA（视觉-语言-动作模型）** — 机器人控制模型。（ch7/ch9）

## 进阶（ch8-10）
- **外部化学习** — 不改权重的进化（工具库 / 知识库 / Skills）。（ch8）
- **Voyager** — 开放世界工具创造范式蓝图。（ch8）
- **Sim2Real** — 仿真到真实迁移。（ch9）
- **A2A** — Agent 间标准化互操作协议。（ch10）
- **Loop 工程** — 循环的瓶颈在验证器。（ch10）
- **预算感知** — 显式引导 Agent 分配计算资源。（ch10）
