# 第 8 章 · Agent 的自我进化

> 来源：原书第 8 章。衍生解释，非逐字原文。

## 核心问题
不修改模型权重，Agent 能否持续变强？

## 核心观点
先在三种学习范式中定位：后训练固化参数（ch7）/ 上下文学习做临时适应 / **外部化学习（本章聚焦，不改权重）**。然后展开其工程实践，围绕两个维度。

## 维度一：从经验中沉淀知识（「越做越熟练」的积累机制）
- **策略摘要**：提炼决策智慧。
- **工作流录制**：固化操作流程。
- **Reflexion 式反思**：沉淀失败教训。
- **Skills**：将领域知识结构化（外部化）。
- **系统提示词优化**：从边界案例中提炼规则（Prompt 蒸馏）。

## 维度二：主动突破工具边界（从使用者到创造者）
在 ch4「主动工具发现」（从已有工具中找合适的）之上更进一步：
- 网络搜索 → 集成现有库 → 从头编写新工具。
- **Voyager**：开放世界中「工具创造」范式的完整蓝图。
- MCP-Zero：主动发现 / 创造工具。

## 关键判断
Agent 从工具的**使用者**变成**创造者**——这是自我进化的核心。外部化学习与 ch7 后训练互补：模型权重更新以周计，而 API 变更 / 需求演化每天都在发生。
