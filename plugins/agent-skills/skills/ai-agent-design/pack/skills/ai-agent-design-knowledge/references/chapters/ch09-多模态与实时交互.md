# 第 9 章 · 多模态与实时交互

> 来源：原书第 9 章。衍生解释，非逐字原文。

## 核心问题
Agent 如何从纯文本走向语音、GUI、物理世界？三个场景（语音 / Computer Use / 机器人）表面差异悬殊，但**延迟与多模态两道坎始终如影随形**，驱动架构从串行流水线向端到端模型演进。

## 语音 Agent：三种范式演进
| 范式 | 特点 |
|---|---|
| 级联流水线 Cascading | ASR → LLM → TTS 串行 |
| 端到端全模态 Omni | 统一模型处理语音 |
| 全双工交互 Full-Duplex | 边听边说，实时打断 |

演进方向：从分离的快慢思考 → 「边想边说」。

## Computer Use（GUI 自动化 Agent）
- 在 OSWorld 等基准上准确率已接近人类水平。
- 但**操作步骤明显多于人类、步骤耗时随任务推进不断增长**——效率差距尚无系统性解法。

## 机器人操作
- 瓶颈已从硬件转到 **VLA（视觉-语言-动作模型）控制层的跨任务泛化能力**。
- 触觉、灵巧手等仍是尚未攻克的硬件短板。
- Sim2Real 迁移是关键路径。

## 共同架构挑战
多模态与实时性，迫使架构从同步串行走向端到端 / 异步内化（呼应 ch4 异步架构矛盾的根本解法）。

## 与其他章节关系
ch4 异步矛盾的「下一代模型在异步环境 RL 内化」在此体现为 VLA。下一章转向多 Agent 协作——另一个维度。
