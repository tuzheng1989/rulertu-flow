# 第 5 章 · Coding Agent 与代码生成

> 来源：原书第 5 章。衍生解释，非逐字原文。

## 核心问题
代码对 Agent 意味着什么？核心论点：**代码不只是写程序的工具，它是 Agent 形式化思考和精确表达的语言**。Coding Agent + 文件系统是所有通用 Agent 最核心的基础。

## 核心观点
- **Coding Agent 成熟度高，主因不是代码模型强，而是软件工程几十年攒下的基础设施——测试套件、类型系统、版本控制——天然构成强大的 Harness**。这个结论可推广到其他 Agent 场景。
- **可靠性 ≠ 不犯错**，而在于每类故障是否都有对应的**检测、恢复、终止**路径。

## 代码生成的六大维度（编程之外的价值）
| 维度 | 价值 |
|---|---|
| **思考工具** | 借助符号计算与约束求解弥补概率思考的不足 |
| **业务规则约束** | 以无歧义方式表达业务规则，在不可逆操作场景提供确定性安全防线（价值远超实现成本） |
| **多媒体生成** | 通过提议者-审核者机制创建 PPT、视频等多模态内容 |
| **系统适配器** | 自动跟随格式演化，实现日志解析与问题诊断全自动化 |
| **生成式 UI** | 动态创建表单、可视化、完整可定制应用，突破纯文本限制 |
| **Agent 自举** | 用代码修复和创造同类 Agent——能创造 Agent 的 Agent |

## 关键判断
代码对 Agent 是真正的**元能力**：既是完成任务的手段，也是积累知识、创造工具、优化自身的机制。
