# 对比框架与模式（Patterns）

> 全书可复用的对比、因果与权衡模式。衍生解释。

## 模式 1：三种学习范式（ch1/ch7/ch8）
| 范式 | 机制 | 周期 | 改权重 |
|---|---|---|---|
| 后训练 | 写入参数 | 以周计 | 是 |
| 上下文学习 | 临时适应 | 单会话 | 否 |
| 外部化学习 | 工具库 / 知识库 / Skills | 持续 | 否 |

## 模式 2：编排模式光谱（ch1）
提示词 → 工作流 → 自主 Agent（风险递增，按序引入）。具体：链式 / 并行 / 路由 / 编排者-工作者 / 评估器-优化器，无通用最优。

## 模式 3：单会话上下文 ↔ 跨会话记忆（ch2/ch3）
单会话上下文工程（ch2）与跨会话记忆 / 知识库（ch3）同属「上下文」支柱，收敛为**双层记忆架构**（常驻概览 + 按需细节）。

## 模式 4：工具五分类（ch4）
感知（只读可缓存）/ 执行（提议者-审核者 + Sidecar）/ 协作（子 Agent 生命周期）/ 事件触发 / 用户沟通——各有设计侧重。

## 模式 5：SFT vs RL（ch7）
**先后关系非竞争**：SFT 先稳定输出格式（记忆），RL 再泛化。
- 数据和环境 > 算法。
- 样本效率是当前瓶颈。

## 模式 6：奖励信号演进（ch7）
二元奖励 → 过程奖励 PRM（逐步验证）→「奖励结果、约束过程」（RLVP）。

## 模式 7：多 Agent 两维度（ch10）
上下文（共享=继承式 / 不共享=独立）× 拓扑（对等 / 管理者 / 去中心化）。
- 核心准则：**协作是否引入生成时不存在的新信息**。

## 模式 8：语音三范式（ch9）
级联流水线 → 端到端 Omni → 全双工；从分离快慢思考 →「边想边说」。

## 模式 9：可靠性范式（贯穿）
- **循环瓶颈在验证器**：proposer-reviewer 终结假成功 / 过早放弃 / 偷懒式假完成。（ch4/ch10/引言）
- 软件工程基础设施（测试 / 类型 / VCS）= 天然 Harness。（ch5）
- 故障三路径：检测 / 恢复 / 终止。（ch5）

## 模式 10：操作系统隐喻（ch10）
Agent : 运行时 = 进程 : 内核；静态前缀=程序，轨迹=内存，LLM=分时 CPU。
- 数据平面=共享文件系统；控制平面=通信与控制（消息总线 / A2A）。

## 模式 11：四类过早终止 vs 验证器（ch10/Loop 工程）
偷懒式假完成 / 过早放弃 / 假成功 → 由扎根真实观测的验证器（代码执行 / 视觉截图 / 工具验证）而非模型自宣称，判定任务完成。
