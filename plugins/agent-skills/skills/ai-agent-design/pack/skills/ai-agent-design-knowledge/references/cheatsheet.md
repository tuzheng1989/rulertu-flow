# 决策速查（Cheatsheet）

> 把作者判断变成可执行的决策规则。查表即用。

## 何时用工作流 vs 自主 Agent（ch1）
先提示词 → 再工作流 → 最后自主 Agent（风险递增）。
任务确定、错误代价高 → 工作流；开放探索、需自主决策 → Agent。

## 何时 SFT，何时 RL（ch7）
输出格式不稳 / 要「记住」特定行为 → SFT。
要泛化 / 探索最优策略 → RL（且 SFT 先行稳定格式，否则奖励无法计算）。
默认：先把 SFT 数据质量做到位，很多场景不必上 RL。**数据和环境 > 算法**；样本效率是瓶颈。

## 何时多 Agent（ch10）
协作能引入生成时不存在的新信息（代码执行 / 视觉截图 / 工具验证）→ 是。
只是重新审视同一段文本（辩论）→ 否，单 Agent 即可。
管理者模式：最强模型 + 最精提示词给**规划 Agent**（它是瓶颈）。

## KV Cache 友好布局（ch2）
前缀稳定（系统提示词 + 工具定义）才能命中缓存；改前缀 = 缓存失效 → 动态内容放后段。

## 上下文压缩（ch2）
不是单纯截断，是主动总结变高密度结构化知识。原始数据被动检索 < 主动提供提炼过的结构化知识。

## 工具安全审查（ch4）
接入第三方 MCP 前：审查**工具描述投毒、工具遮蔽、凭证管理**。
执行工具：提议者-审核者（事前审批 + 事后验证）。
底线：**参数传递保真性**（模型感知世界 = 工具操作世界）。

## 可靠性判据（ch5/ch10）
可靠性 ≠ 不犯错 = 每类故障都有**检测 / 恢复 / 终止**路径。
任务完成由**验证器（真实观测）**判定，非模型自宣称。
警惕三类过早终止：偷懒式假完成 / 过早放弃 / 假成功。

## 记忆策略（ch3）
双层架构：JSON Cards 常驻概览 + 上下文感知检索按需细节。按简单性 vs 表达力张力，从四策略中选。

## 评估可信度（ch6）
观察 → 假设 → 实验 → 验证 闭环。改动是否真变好：看**统计显著性**，非直觉。

## Harness 杠杆与护城河（后记）
harness 是短期最锋利杠杆（52.8% → 66.5%）。但模型会一层层吃掉它；长久护城河在技术之外（数据 / 渠道 / 信任 / 网络效应 / 人机协作）。

## 术语快查
reasoning=思考，inference=推理（勿混）。SFT 记忆，RL 泛化。Agent=LLM+上下文+工具。
