# 第 7 章 · 模型后训练

> 来源：原书第 7 章。衍生解释，非逐字原文。

## 核心问题
如何让模型更聪明？本质：**把交互策略写入参数**。三阶段全景：预训练 / SFT / RL。

## 核心观点
- **SFT 与 RL 是先后关系，不是竞争关系**：SFT 先把输出格式稳定下来（否则 RL 奖励信号无法计算），RL 再在此基础上学会泛化。
- **「SFT 记忆、RL 泛化」不是口号，是可测量的现象**。
- 两条贯穿全章、比任何算法都重要的判断：
  1. **数据和环境比算法更重要**——现成 RL 算法会用就行，差距在仿真环境保真度与训练数据质量；很多场景 SFT 数据质量到位，甚至不需要 RL。
  2. **当前 RL 的主要瓶颈是样本效率**。

## 关键概念
- **RLHF**：从人类偏好训练奖励模型。
- **奖励信号设计**：从二元奖励 → 过程奖励（PRM，「逐步验证」）→ 「奖励结果、约束过程」的验证路径惩罚。
- **RLVP**（作者提出）：奖励结果、惩罚路径，并用可达进展的部分奖励救回全败组的采样。
- **On-Policy Distillation**：让每步信号更密集，提升样本效率。
- **多轮 RL**：信用分配与奖励设计（从单轮到多轮）。
- RL 学习工具调用。

## 两个最有希望的方向（共同点）
On-Policy Distillation 与 RLVP——把环境和数据里本就存在、却被纯结果奖励浪费掉的信息，重新变成模型能学的东西。

## 权衡与反例
- DPO 与各类 RL 各有失败模式（如 Agent 缺乏「时间感」：紧迫 / 持久 / 警觉）。
- 算法选择不是关键，环境与数据才是。
