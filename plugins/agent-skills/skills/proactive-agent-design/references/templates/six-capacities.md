## 闭环走查

逐例记录原始材料、每环做了什么、权限依据、外部生效状态和反馈去向：一条真实变化，一条合理不行动／需求消失，一条中断或部分失败。无法接通的接口列为缺口。

评审模式可改用「证据 → 最早断点及下游放大 → 人补位 → 修补 → 验证 → 未知项」，不必重做不受影响的设计。
