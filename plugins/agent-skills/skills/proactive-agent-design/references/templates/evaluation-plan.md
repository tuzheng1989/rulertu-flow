# 主动行为评测计划

【实现约定】规划与已运行结果分开；可接受行为允许多解。阈值从用户目标与任务后果确定，无依据时留待定。

## 输入规范声明

- 待评系统的持续职责、约束与权限版本：待定。
- 既有状态及原始信源，随时间对 Agent 可见的材料：待定。
- 输入是否转述了本次问题或暗示行动，包括文件名、摘要与提示词：待定；如有，区分执行测试与主动发现测试并改写。
- 标准答案、机会标注和评分规则仅供评测侧；标注来源及争议处理：待定。

## 情境与长程计划

| 原始情境与时间变化 | 可接受行为集合及档位触发器 | 故障／正确不行动所属环 | 观测、评分者与状态 |
|---|---|---|---|
| 真实需求出现／期限变化 | 待定 | 待定 | 未运行 |
| 无关信号／证据未定／需求消失 | 待定 | 待定 | 未运行 |
| 用户沉默／权限撤销 | 待定 | 待定 | 未运行 |
| 中断重启／部分失败／结果未知 | 待定 | 待定 | 未运行 |
| 跨周月偏好漂移／过期信息重查 | 待定 | 待定 | 未运行 |

按任务补充塑造效应与代理指标偏差。写明长程观察时长、回放冻结的时间与工具状态、模拟不能验证的因果效应、真实用户投入和评分分歧；不适用的项目写理由。

## 报告方式

分别报计数与比率、窗口、样本范围、三层结果和未决项。解释即使任务成功仍可能净负收益的情形。上线判断所需证据不足时，保留待验证结论。
