# Arbitration：仲裁

【原文】值得追求的目标还不是值得此刻执行的介入。论文 §4.4、图 10 给出四类检查：证据／置信是否足够、价值是否超过成本、时机是否合适、风险与可撤回性是否可接受；判断始终受已有权限限制。

【导读】这是框架的枢纽，不能用静态「全自动／全提醒」替代。按任务段组合「档位＋触发器」，而非给整个任务一个统一权限等级。

## 分段选择

【实现约定】下列名字便于设计讨论，不是论文的固定线性等级。确认可能比安静准备更打扰，执行风险也取决于对象；按多维条件比较。

| 形态 | 适用条件与可用动作 | 下一次改变决定的信号 |
|---|---|---|
| 静默值守／延后／停止 | 净收益低、时机不佳、需求未定或已消失；明确保留监控还是关闭待办 | 新证据、复查时点、需求恢复；已消失则取消 |
| 补证／准备／草稿 | 需先减小不确定性，或可在委托内无副作用地整理选项 | 关键证据核实、准备完成、有效期到期 |
| 建议／提醒 | 信息对用户有价值，且呈现收益足以覆盖注意力成本 | 期限临近、证据变化、用户修改或拒绝 |
| 询问／请求确认 | 必须由人解决的取舍或授权边界，且问题值得占用注意力 | 明确答复；无回复则按等待策略处理 |
| 在授权内执行 | 证据、净收益、时机、风险均满足条件且 Action 确实支持 | 授权撤销、证据失效、风险升高、部分失败即重新仲裁 |

每段记录：当前可选形态、权限依据、证据成熟度、期限结构、价值与成本、撤回能力、升级触发器、降级／停止条件、等待与无人回复策略。

## 取舍准则

- 【导读】可撤回性是一等变量。草稿可编辑、执行可回滚和中途可接管，分别改变可选动作；实际做不到的恢复能力不能计入风险折扣。
- 【导读】严重性与证据成熟度分别回答投入价值和当前动作。高后果低证据时，可优先做有依据的补证与准备；期限逼近不自动突破权限。
- 【原文＋导读】把打扰、核对、纠错、等待与资源消耗计入。注意力定价为零，会产生「证明价值型过度介入」。
- 【导读】缺少期限或可撤回性等会翻转档位的变量时，追问该变量，先保留分支方案。介入没有脱离情境的唯一答案。

【实现约定】净价值可概念化为「相对等待的预期目标收益 − 工具／资源成本 − 用户打扰与审核纠错成本 − 残余风险」。量纲、权重和阈值要本地标定；算不清时保留各项与敏感性，不伪造分数。

## 条件示例【实现约定】

职责为协助安排已批准的行程，收到正式改期通知：可在已授权的只读范围内核对订单、整理差异；是否立刻提醒取决于可改签窗口和用户当下注意力；是否提交变更还取决于新日期核实、费用与明确授权。缺任何一个决定性变量就标待定。通知后来撤回则撤销相关待办，不能因已经投入成本而继续推进。

**失败与验证**：一刀切、打断风暴、忽视窗口、越权执行。固定原始变化，分别改变证据可靠性、期限、撤回能力和授权，检查是否调整选择；加一例用户不响应，确认不会把沉默当许可。

**环间接口**：输入来自预判的价值比较和议程候选；可选空间由 Action 能力约束；输出包括不行动及复查条件；Adaptation 可学时机与阈值，但不能自行扩大授权。
