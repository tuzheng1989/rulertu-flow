# 主动行为评测

【原文】论文 §5、表 2、图 13 从任务效用、机制有效性、用户体验三层评测。合理不行动、用户负担和长期适应都是质量的一部分。图 15 是跨行业趋势，不是三层评测图。

## 先检查任务表述污染【导读】

输入若写「会议改期，请修改行程」，人已替 Agent 发现问题并选择行动，主要测到执行能力。主动性评测退回「持续职责＋既有状态＋按时间到来的原始变化」；不在输入、文件名、检索摘要或提示词中暗示冲突与解决步骤。

持续职责本身是合法委托，不是污染。区分职责与本次事件的具体任务答案。标准答案、机会标注和评分规则留在评测侧，Agent 只能见在该时间实际可得的材料。

【导读】不要将此概括成「所有现有 benchmark 都测不出主动性」；论文也讨论专门的主动行为评测。应逐套检查，描述它实际覆盖哪部分机制。

## 定义评测单位与口径【实现约定】

先由职责、约束、机会窗口定义标注单位：一项真实需求、一个事件窗口还是一次决策点。为每单位列出可接受行为集合及其时间条件；合理核实、静默、延后、取消可以是正确答案。用去重规则避免同一需求被十次提醒算作十次发现。

| 量 | 定义与用途 |
|---|---|
| TP／FN | 应发现且在窗口内识别的需求／该发现而漏掉的需求；发现不要求立即向用户发消息 |
| 发现率（召回） | TP ÷ (TP＋FN)；报告匹配条件和窗口 |
| 候选发现精确率 | 正确候选数 ÷ 全部提出的候选数；候选与用户介入分开记 |
| 多余介入占比 | 不满足可接受行为或时机的介入数 ÷ 全部实际介入数；重复、过早、失效后继续均需分类 |
| 误报率 | 无需介入窗口中发生多余介入的窗口数 ÷ 全部无需介入窗口数；分母不同于上一项 |
| 合理不行动正确率 | 应核实／等待／静默／取消的单位中选择可接受行为的比例；同时查是否漏掉真实机会 |
| 净收益 | 相对响应式或规则基线的目标收益，减计算、工具、人工审核纠错、打扰与恢复成本；不同量纲分项报告，需加权时声明依据 |

分母为零标记 N/A 并保留计数，不记成满分。发现率高且多余介入低仍不足以证明授权或执行正确。

## 三层指标

| 层 | 应回答的问题 | 观测与失败定位 |
|---|---|---|
| 任务 | 结果正确吗，提前处理有净收益吗？ | 达成率、窗口内发现、额外收益、延误损失、时间／计算／人工成本；与基线比较 |
| 机制 | 哪环先断，哪些下游环放大？ | 感知覆盖与新鲜度、预测依据与校准、议程筛选／重启恢复、仲裁档位与时机、执行状态与撤回、反馈归因与漂移适应 |
| 用户 | 人是否更省心且保有控制？ | 核对／补充／纠错耗时、打断次数与恢复时间、修改／拒绝／停止／接管成功率、长期正确采纳与复核 |

【导读】任务全绿而人工投入更大，仍可能是净负资产。不能只奖励行动次数；必须纳入需求消失与证据不足的正确处理。

## 情境覆盖与长程

至少覆盖与本系统有关的变化：真实机会、无关噪声、证据未定、窗口将关闭、原需求消失、权限撤销、执行部分失败、用户沉默、旧偏好与新证据冲突、中断重启、信息过时重查。每项写清可观察预期行为，阈值由任务风险与用户目标确定，未知阈值标待定。

【原文＋导读】跨周／月观测长期议程、漂移和用户采纳策略。用事件回放或分支模拟比较方案时冻结材料可见性、工具状态和时间；真实主动情境具有历史依赖，干预会改变用户和环境，离线回放不能证明长期因果效应。分别报告模拟结果与真实使用结果，记录局限。

【实现约定】最小评测记录：事件时间线、可见材料、职责及权限版本、需求／不行动标注、内部候选、介入与执行轨迹、三层成本、六环归因、基线、评分者分歧和未知项。此处设计评测计划，不把未运行的情境宣称为已通过。
