## 转述修正与保留边界

以下将校准事实与交接的推演分别处理：

- Awareness 从交接的三子能力补成含运行时架构的四部分；保留职责锚与监控拓扑的【导读】解释。
- 原文有用户与世界建模，但不要求每类任务同等依赖两者。双路输出的工程接口保留【导读】。
- 原文反馈讨论含隐式反馈、任务中反思、长期校准；快慢两时间尺度为便于实施的归纳。
- 三层评测定位到图 13；图 14 和图 15 分别涉及应用转变、跨行业趋势。
- 交接的详细行程例、逐段授权方案、待办字段、三自、三段加枢纽、最小完备性反事实论证，按【导读】或【实现约定】使用；本次未确认详细行程例为当前 PDF 的原例，不称“原文行程例”。
- 「现有 benchmark 全是人指派」「无系统两轴皆高」收窄为逐套评测检查与综述样本观察。四维可分别设计，不声称已实证统计独立。
- 领域成熟度矩阵、证据成熟度启发式、塑造效应与代理人错位警示保留【导读】；授权函数、放大器模型与高层目标权规范保留【共创】。
