# 四维坐标与剩余决策空间

【原文】主动性是在受委托的剩余决策空间中判断什么值得处理，并决定是否、何时、怎样介入。指令写明目标与硬约束，执行时仍可能需要取舍、补齐步骤、处理意外和重规划。来源：论文 §1–2，概念图 2–4；核对口径见 [sources.md](sources.md)。

| 维度 | 设计问题 | 需要的证据 |
|---|---|---|
| 智能水平 | 能理解并解决哪些问题？何时失效？ | 任务结果、能力边界与失败样本 |
| 对齐 | 行为是否服务人的目标、价值和约束？ | 受益者、冲突裁决、约束遵守与纠正记录 |
| 主动性（发起侧） | 工作如何被发现、提出、持续追踪？ | 无新指令的变化事件到待办的轨迹 |
| 自主程度（执行侧） | 获准独立执行到哪一步？ | 分段权限、实际工具能力、接管与撤回记录 |

【导读】四维分开评估，避免用执行自动化代替发起能力，或用能力成绩代替授权依据。「独立变化」指可分别设计，不是统计独立的实证结论。

【导读】为何分成六环，可从三方面检验：结构上是构造待办、仲裁枢纽、执行学习；反事实上，逐环移除会分别失去看见变化、理解后果、维持承诺、判断介入、落实恢复、从反馈校准的能力；对照现有系统，可定位哪个职责尚需人补位。这是最小完备性的分析论证，不是论文证明六个独立模块必不可少。

【原文】主动性是光谱，同一系统可混用响应式、触发式和预判式行为。论文 §6.14.1 以响应、触发、预测、持续委托、自生成高层议程五档比较其样本；发起与执行权限两轴可错位，自动科研与智能家居是不同组合。

【导读】不把综述样本结论写成所有系统的全称判断。定时提醒可能对用户有价值，但要辨明「人已定义工作」和「系统从职责中发现工作」。档位是描述工具，不是越高越好的成熟度分数。

定位前先写三项：

- **委托**：代表谁，追求什么目标，硬约束及有效期是什么。
- **剩余空间**：允许自行取舍的事项；不确定时由谁决策。
- **权限**：可用信源、工具、执行范围、撤回方式及委托更新者。

【导读＋共创】保持高层目标的人类修订权，允许 Agent 生成和更新受托目标之下的工作议程。发现更多工作不自动扩大执行权限。
