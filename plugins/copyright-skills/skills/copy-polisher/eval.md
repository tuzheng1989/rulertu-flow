# Copy Polisher 自检清单

改稿后用。逐条回答 pass 或 fail。任一条 fail，回去修订草稿，再查一遍。

检测模式不适用本清单：检测请求只要求返回"套路名 + 原文引用 + 一句话改法"，不重写、不打分、不猜作者。

## 编辑原则

1. 改稿是否保留了用户的核心观点，没有添加原文没有的观点、例子、数据、引言或立场？
2. 是否保留了作者有辨识度的词汇、节奏、直率程度、幽默、迟疑、跑题和打磨程度？
3. 强有力的人味句子是否原样保留，没有为了统一性而重写，也没有把每段改得一样整洁？
4. 删改量是否与实际的 AI 套路量成正比，没有过度压缩以至于磨掉作者个性？
5. 是否在观点需要直入时删掉了通用铺垫，同时保留了能提供上下文、张力或人物形象的个人题外话？
6. 句子是否都"挣到"了各自的位置，用到具体事实、受保护的细节和直接动词？
7. 是否保留有用的锋芒（强观点、直率措辞、幽默、诚实承认），没有换成更"安全"的措辞？
8. 真正缠绕难懂的句子是否被拆解，同时清晰的口语节奏、短句碎片、节奏变化得以保留？
9. 是否用主动语态，主语尽量是人，没有让无生命的东西做人类的动词？
10. 文章结构是否保留，除非原结构在伤害文章？若做了重组，是否在"改了什么"里说明了原因？

## 套路清除

### 内容模式（第 1-6 条）

1. 是否删除了过度强调意义、遗产、更广泛趋势的表述（"标志着""见证了""为……奠定基础"等）？
2. 是否删除了过度强调知名度、罗列媒体来源而不给上下文的表述？
3. 是否删除了句末假装解释意义的 -ing 短语（"凸显……""反映……""彰显……"）？
4. 是否删除了宣传式、广告式语言（"充满活力的""令人叹为观止的""坐落于"等）？
5. 模糊归因（"专家认为""研究表明"）是否替换成具名来源，或在无来源时向用户标出？
6. 公式化的"挑战与未来展望"段落是否被具体事实替换？

### 语言和语法模式（第 7-12 条）

7. AI 高频词（"此外""至关重要""格局"等）是否删除，**除非**它表达真实的强调、对比、不确定或属于作者口语节奏？
8. 系动词回避（"作为……""拥有……"）是否改回简单的"是""有"？
9. 否定式排比（"不仅仅是 X，而是 Y"）是否改为直接陈述？
10. 三段式列举是否被打散为两项或四项？
11. 同义词循环（主人公/主要角色/中心人物）是否统一为重复使用的清晰用词？
12. 虚假范围（"从 X 到 Y"但不在同一尺度）是否被删除？

### 风格模式（第 13-18 条）

13. 破折号是否克制使用，删除了堆叠和装饰性破折号？
14. 粗体是否只用于真正需要强调处，没有机械地满篇加粗？
15. 内联标题垂直列表（"**X：** Y"）是否改为流畅的散文？
16. 标题大小写问题是否修正（中文场景通常不适用）？
17. 装饰性表情符号是否从标题和列表中删除？
18. 弯引号/英文引号问题是否修正为中文引号？

### 交流模式（第 19-21 条）

19. 协作交流痕迹（"希望这对您有帮助""请告诉我"）是否删除？
20. 知识截止日期免责声明是否删除或替换为具体来源？
21. 谄媚讨好语气（"好问题！""您说得完全正确"）是否删除？

### 填充词和回避（第 22-24 条）

22. 填充短语（"为了实现这一目标""值得注意的是"）是否替换为简洁说法？
23. 过度限定（"可能潜在地或许"）是否精简？
24. 通用积极结论（"未来光明""激动人心的时代"）是否替换为具体的下一步或事实？

### 创作类套路（第 25-32 条）

25. 清嗓子开头（"这么说吧""老实讲"）是否删除，直接进入观点？
26. 伪洞见铺垫（"多数人不知道的是"）是否删除，让观点自己站住？
27. 冒号抖包袱（名词短语 + 冒号 + 戏剧性揭晓）是否改为正常句子？
28. 假高潮金句结尾是否删除（不是改写成更好的比喻），落在文中已有的具体话上？
29. 逢段升华（每段结尾拔高一句"意义"）是否删除？
30. 名词化排比（"是 X、是 Y、是 Z"）是否替换为具体行为或事实？
31. 段标题同质化（通篇"01 概括句"）是否提示作者调整？
32. 升维套话（"在某种意义上""从更高维度看"）是否删除？

## 源码注释审校（外审校准，见 SKILL 同名小节）

33. 高频规范化措辞（"硬性约束""镜像某模块""职责归属""不得改动""单一真相源"）是否按"表达 × 出现次数"点名，只压密度不扫光？
34. 批次/阶段/分组编号（"批次 3.3""阶段 0""Treatment/对照"）是否删除编号而保留约束本身？
35. 注释完整性密度是否做了减法（简单函数不配齐"职责—约束—分层—降级—返回"全模板）？
36. 替换词是否分散（同一套路词未全库统一替换成另一个固定词）？
37. 保留清单是否完好：字段契约对应、领域具体约束、端口/阈值/降级规则等连续性证据未被误删？

## 最终通读

1. 草稿是否避免了机械对称、重复句式和堆叠的短句碎片？
2. 作者读到改后稿，会不会认出这还是自己的声音？
3. 把改后稿大声读给一位挑剔的同事听，会不会显得自然？
4. 改稿模式的输出是否包含改后全文和一段"改了什么"（每条：套路名 + 原文引用 + 改法）？
5. 检测模式的输出是否只列套路清单（命名 + 引用 + 改法），没有重写、打分或猜测作者？
