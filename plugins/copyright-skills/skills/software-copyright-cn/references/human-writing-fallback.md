# 改稿降级审校

仅在当前会话无法调用同插件 `copy-polisher` 时使用。目标是最小编辑，不是重写。

1. 保留专名、数字、日期、版本、限制、步骤编号、按钮文字和技术结论。
2. 把“作为……”“拥有……”“具备……能力”等绕写改成简单主谓句；优先使用“系统读取、校验、生成、显示、保存”等直接动词。
3. 删除无证据的意义拔高、行业趋势、宣传形容词、模糊归因、通用积极结尾和“希望对您有帮助”等交流痕迹。
4. 打散机械的三段式排比和同构段落，但保留操作手册所需的编号步骤。
5. 长短句交替。一个段落围绕一次操作或一个可核对结果，不在段尾重复升华。
6. 改完逐句对照事实表；任何新增事实、因果或性能判断都撤回。

完成后在审计记录写明：未调用 `copy-polisher`、采用本文件规则、修改了哪些段落，并保留改前稿便于人工复核。
