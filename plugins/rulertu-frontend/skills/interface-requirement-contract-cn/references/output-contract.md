|---|---:|---|
| 需求追踪表 | 是 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 页面状态矩阵 | 是 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 字段映射表 | 是 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 交互与权限规则 | 是 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 验收例子与待确认项 | 条件必填 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 限制与未验证项 | 是 | 精确说明受阻范围及其对结论的影响 |
| 下一步 | 是 | 给出责任角色、输入、动作和完成信号 |

## 证据状态

- **已核验**：本轮实际读取或运行，记录位置与结果。
- **用户提供**：来自用户材料，未被独立工具验证。
- **推断**：由证据支持但仍需实验或责任人确认。
- **受阻**：工具、权限、环境或材料使验证无法继续。
- **未执行和未验证**：计划中的动作，不能写成已完成。

## 完成门

- [ ] 对象、版本、环境与范围可唯一定位。
- [ ] 需求追踪、字段来源和七类页面状态均可定位。
- [ ] 401/403/404/409/422/429/5xx 只覆盖接口实际可能返回的分支。
- [ ] 有写操作时覆盖冲突、失败恢复和回滚；纯只读页面不强制回滚。
- [ ] 每条验收例包含给定条件、操作、可观察结果与证据位置。
