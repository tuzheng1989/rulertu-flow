# 前端功能故障定位

按“服务端响应 → 客户端适配 → 缓存 → 全局状态 → 组件属性 → 事件 → 页面元素”定位最早出错的一层。回退文案、可选链和空数组可能隐藏错误，排障时核对原始值。

每层记录一个可证伪问题：

| 层 | 要比较的证据 |
|---|---|
| 响应 | URL、参数、状态码、响应体、账户权限 |
| 适配 | 输入 DTO、输出领域对象、被丢弃或被补默认值的字段 |
| 缓存 | 缓存键、命中数据、失效/刷新时机 |
| 状态 | 当前请求身份、更新顺序、数据所有者 |
| 组件 | 实际 props、条件分支、memo 依赖 |
| 事件 | 命中元素、禁用条件、冒泡、重复触发 |
| DOM | 文本、属性、焦点、可见/遮挡状态 |

最小回归测试必须在修复前失败、修复后通过，并针对根因而非实现细节。字段契约问题至少覆盖缺字段、空值、类型变化和错误响应。竞态问题要用可控 Promise、假时钟或请求延迟稳定复现，不依赖“快速点几次有时出现”。
