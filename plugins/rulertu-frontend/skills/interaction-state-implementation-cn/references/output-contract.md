# 页面交互与状态开发输出契约

| 字段 | 必填 | 验证要求 |
|---|---:|---|
| 修改文件清单（实施任务）或拟改位置（只读任务） | 是 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 状态转换表 | 是 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 字段与错误映射 | 是 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 回归测试结果（已运行）或待执行测试（只读任务） | 是 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 未联调与残余风险 | 条件必填 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 限制与未验证项 | 是 | 精确说明受阻范围及其对结论的影响 |
| 下一步 | 是 | 给出责任角色、输入、动作和完成信号 |

## 证据状态

- **已核验**：本轮实际读取或运行，记录位置与结果。
- **用户提供**：来自用户材料，未被独立工具验证。
- **推断**：由证据支持但仍需实验或责任人确认。
- **受阻**：工具、权限、环境或材料使验证无法继续。
- **未执行和未验证**：计划中的动作，不能写成已完成。

## 完成门

- [ ] 对象、版本、环境与范围可唯一定位。
- [ ] 状态方案沿用项目既有框架且 query key 或 reducer 身份完整。
- [ ] A→B→A、逆序返回、取消、卸载和当前请求失败按实际竞态风险覆盖。
- [ ] 实施任务提供真实测试结果；只读任务提供拟改位置与待执行断言。
- [ ] 有持久化写入时核对刷新后结果；纯客户端派生状态不强制回滚。
